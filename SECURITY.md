# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately**, not in a public issue.

Use GitHub's private vulnerability reporting: go to the **Security** tab of this repository and click **Report a vulnerability**. The report is visible only to the repository maintainer until it is resolved.

Please include what you observed, how to reproduce it, and the impact you expect.

This is a personal project. We cannot promise a response time or a fix schedule, but reports are read and taken seriously.

## Scope

This repository is a study application (Django REST Framework + React) and its development harness. It is not operated as a public service, so there is no production deployment to attack. Reports about the code in this repository are still welcome.

# セキュリティポリシー

## 脆弱性の報告

脆弱性は**公開イシューではなく非公開で**報告してください。

GitHub の非公開報告機能を使います。このリポジトリの **Security** タブを開き、**Report a vulnerability** をクリックしてください。報告内容は、解決されるまでリポジトリ管理者のみが閲覧できます。

観測した事象・再現手順・想定される影響を添えてください。

個人プロジェクトのため、応答時期や修正時期をお約束することはできませんが、報告は必ず読み、真摯に扱います。

## 対象範囲

このリポジトリは学習アプリ（Django REST Framework + React）とその開発ハーネスです。公開サービスとして運用してはいないため、攻撃対象となる本番環境はありません。リポジトリ内のコードに関する報告は歓迎します。
