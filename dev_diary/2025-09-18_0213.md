## エラー対応

### 発生したエラーの詳細

**エラー1: subjects.map is not a function**
- エラーメッセージ: `TypeError: subjects.map is not a function at renderSubjectSelection (Register.tsx:360)`
- 発生状況: 会員登録画面読み込み時
- 環境: 開発環境、React アプリケーション
- 影響: 科目選択セクションが表示されず、登録プロセスが中断

**エラー2: 型定義不整合エラー**
- エラーメッセージ: `TS2345: Argument of type 'Subject[]' is not assignable to parameter of type 'SetStateAction<Subject[]>'`
- 発生状況: TypeScriptコンパイル時
- 環境: 開発環境、TypeScript
- 影響: アプリケーションのビルドが失敗

### エラーの原因

**エラー1の原因:**
- 根本原因: APIレスポンス形式がページネーション形式（`{count, results[]}`）なのに、コードは配列を期待
- 原因箇所: `Register.tsx:148` - `setSubjects(response.data)`
- 関連する問題: Django REST FrameworkのPageNumberPaginationが使用されている
- APIから`{count: 3, results: [...]}` 形式で返却されているが、フロントエンドは配列を期待

**エラー2の原因:**
- 根本原因: 型定義の重複と不整合
- 原因箇所: `Register.tsx:37-41` と `services/types.ts:125-132`
- 関連する問題: `description`プロパティが必須（Register.tsx）とオプション（types.ts）で異なる定義

### 実施した対応

**エラー1への対応:**
- 修正: `response.data.results || response.data`でレスポンス形式を正規化
- 理由: ページネーション形式と配列形式の両方に対応するため
- 追加対応: `SubjectService`クラスで統一的な処理を実装
- 動作確認: 個人登録・組織登録で科目選択セクションが正常表示されることを確認

**エラー2への対応:**
- 修正: Register.tsx内の重複型定義を削除し、`services/types.ts`からインポート
- 理由: 型定義の一元管理で整合性を保つため
- 修正内容: `import { Subject } from '../services/types'`を追加
- 動作確認: TypeScriptコンパイルエラーが解消されることを確認
