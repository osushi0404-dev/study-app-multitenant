### 第1回実装時のエラー

#### 発生したエラーの詳細
- **エラーメッセージ**:
  ```

  src/pages/Dashboard.tsx
  Line 250:23: React Hook "useMemo" is called conditionally.
  React Hooks must be called in the exact same order in every component render.
  Did you accidentally call a React Hook after an early return?
  react-hooks/rules-of-hooks
  ```
- **発生状況**: 初回実装後、フロントエンドでコンパイルエラー
- **環境**: 開発環境、React 18、TypeScript
- **影響範囲**: ダッシュボード画面が表示されない

#### エラーの原因
- **根本原因**: React Hooksのルール違反（条件付きフック呼び出し）
- **原因箇所**: `frontend/src/pages/Dashboard.tsx:250行目`
- **詳細**: `useMemo`が早期リターン（`if (loading || !dashboardData)`）の後に配置されていた
- **背景**: 初回実装時に、関数定義とフック配置の順序を誤った

#### 実施した対応
- **修正内容**:
  - `useMemo`と`renderSubjectSelection`関数を早期リターンの前（106-175行）に移動
  - 重複していた古いコード（318-385行付近）を削除
- **修正理由**: React Hooksは全てのレンダリングで同じ順序で呼び出される必要があるため
- **動作確認**: フロントエンド再起動後、コンパイルエラーが解消し画面表示を確認
