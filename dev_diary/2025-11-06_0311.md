## エラー対応

### 発生したエラーの詳細
- **エラーメッセージ**:
  ```
  AttributeError: module 'problems.models' has no attribute 'question_image_upload_path'
  ```
- **発生状況**: マイグレーション作成コマンド（`makemigrations problems`）実行時
- **環境**: 開発環境、Docker、Python 3.11、Django 5.x
- **影響範囲**: マイグレーション作成ができず、モデル変更をデータベースに反映できない

### エラーの原因
- **根本原因**: 既存のマイグレーションファイル`0008_add_problem_images.py`が削除された関数を参照していた
- **原因箇所**: `backend/problems/migrations/0008_add_problem_images.py` 23行目、39行目
- **詳細**:
  - `question_image_upload_path()`と`explanation_image_upload_path()`関数をモデルから削除
  - しかし、過去のマイグレーションファイルがこれらの関数を`upload_to`パラメータで参照
  - Djangoがマイグレーションファイルをロードする際に、存在しない関数を参照してエラー

### 実施した対応
- **修正内容**: 既存マイグレーションファイル`0008_add_problem_images.py`を修正
  - `import problems.models`と`import problems.validators`の行を削除
  - `upload_to`パラメータを動的関数参照から固定文字列に変更
    - 変更前: `upload_to=problems.models.question_image_upload_path`
    - 変更後: `upload_to='problems/questions/'`
  - バリデーター参照も削除（当該フィールドは後で削除されるため問題なし）
- **修正の理由**:
  - 過去のマイグレーションファイルは歴史的記録として保持する必要がある
  - 削除された関数への参照を固定値に置き換えることで、マイグレーション履歴の整合性を保つ
  - 全データがnullのため、`upload_to`の値は実質的に影響しない
- **代替案**: マイグレーションファイルを削除する案もあったが、本番環境への影響を考慮して採用せず
- **修正後の動作確認**:
  - `makemigrations`コマンドが正常に完了
  - 新規マイグレーション`0009_optimize_image_path_management.py`を手動作成
  - `migrate`コマンドが正常に完了
  - データベーススキーマが期待通りに変更されたことを確認

## 技術的な詳細

### 実装した主要な変更

#### Subjectモデル（最終形）
```python
class Subject(models.Model):
    image_directory = models.CharField(
        max_length=200,
        blank=True,
        default='',
        verbose_name='画像ディレクトリ',
        help_text='科目の画像ベースディレクトリ（例: problems/aws-clf）'
    )

    def get_image_base_directory(self):
        if self.image_directory:
            return self.image_directory.rstrip('/')
        subject_slug = self.name.lower().replace(' ', '-')
        return f'problems/{subject_slug}'

    def get_question_image_directory(self):
        return f'{self.get_image_base_directory()}/questions'

    def get_explanation_image_directory(self):
        return f'{self.get_image_base_directory()}/explanations'
```

#### Problemモデル（画像フィールド部分）
```python
class Problem(models.Model):
    question_image = models.CharField(
        max_length=255,
        blank=True,
        null=True,
        verbose_name='問題画像ファイル名'
    )
    explanation_image = models.CharField(
        max_length=255,
        blank=True,
        null=True,
        verbose_name='解説画像ファイル名'
    )

    def get_question_image_url(self):
        if not self.question_image:
            return None
        directory = self.subject.get_question_image_directory()
        return f'/media/{directory}/{self.question_image}'

    def get_explanation_image_url(self):
        if not self.explanation_image:
            return None
        directory = self.subject.get_explanation_image_directory()
        return f'/media/{directory}/{self.explanation_image}'
```
