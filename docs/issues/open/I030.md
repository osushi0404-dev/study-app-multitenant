# I030: GitHub MCP の導入・設定（issue/PR 高度操作の実現）

## 関連資料
- docs/proposals/I026_ai_dev_improvement_proposal.md（改善案 B）

## 背景/目的
- 現状の `gh` CLI では PR の全コメント一括取得・差分の直接解析・issue のラベル操作等が煩雑
- GitHub が公式提供する MCP サーバー（`@modelcontextprotocol/server-github`）を導入することで、Claude が GitHub API を直接活用できるようになる
- `/code-review`・`/plan-issue`・`/close` フェーズの品質と自動化度を向上させる

## スコープ
### 含む
- GitHub MCP サーバーのインストール・認証設定（PAT の発行と設定）
- プロジェクト固有の MCP 設定ファイル作成（`.claude/` 配下）
- 動作確認（issue 参照・PR コメント取得等）
- 設定手順の runbook への記載

### 含まない
- 他 MCP（Sequential Thinking・Web Search 等）の同時導入
- 既存スキルへの MCP 活用の組み込み（別途検討）

## 受け入れ条件（Acceptance Criteria）
- [ ] Claude が GitHub MCP 経由で issue のコメントを取得できる
- [ ] Claude が GitHub MCP 経由で PR の差分・コメントを取得できる
- [ ] PAT がファイルにハードコードされていない（環境変数 or secrets 管理）
- [ ] MCP の設定方法が runbook に記載されている

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: `.claude/` 配下に MCP 設定ファイル追加

## Danger Ops（有/無）
- 無（PAT の発行・設定はユーザーが行う）
