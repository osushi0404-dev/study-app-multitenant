# I009: I006振り返り - スキル・規約の改善

## 背景/目的
- I006対応の振り返りで以下の問題が発覚した:
  1. /plan スキルがヒアリング不足のまま仕様を決定した
  2. 計画変更時に関連ドキュメント（review/auto_test/manual_test）を更新しなかった
  3. /close スキルで PR のベースブランチを誤って main にした
  4. /implement スキルでテスト環境を未確認のままテストを実行し、テストファイルの形式を承認なく変更した
  5. /issue-bootstrap スキルの採番ロジックが git 履歴を考慮しておらず、既存番号を重複採番した
- 同じミスを繰り返さないためにスキル・規約を改善する

## スコープ
### 含む
- `.claude/skills/plan/SKILL.md`: 承認ポイント提示前のヒアリング自己チェック追加
- `docs/runbooks/plan-writing-rules.md`: 計画変更時の関連ドキュメント更新ルール追加
- `.claude/skills/close/SKILL.md`: PR ベースブランチは develop を使う旨の注記追加
- `.claude/skills/implement/SKILL.md`: テスト実行前の環境確認・テスト形式変更禁止ルール追加
- `.claude/skills/issue-bootstrap/SKILL.md`: 採番時に git 履歴も確認するコマンドに修正

### 含まない
- 実装コードの変更
- 既存ドキュメントの大幅な再構成

## 受け入れ条件（Acceptance Criteria）
- [ ] plan/SKILL.md に「仕様を自己決定していないか」自己チェック手順が追加されている
- [ ] plan-writing-rules.md に「計画変更時は review/auto_test/manual_test も更新する」ルールが追加されている
- [ ] close/SKILL.md に「PR ベースブランチは develop」旨の記載がある
- [ ] implement/SKILL.md に「テスト環境確認」「テスト形式変更禁止」ルールが追加されている
- [ ] issue-bootstrap/SKILL.md の採番ロジックが git 履歴も参照するよう修正されている

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: なし（スキル・規約ドキュメントのみ）

## Danger Ops（有/無）
- 無
