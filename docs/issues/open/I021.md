# I021: ユーザー科目自己登録機能の実装（アカウント登録時選択 + 後から追加・削除）

## 関連資料
- I017: 科目管理画面UX刷新（科目の登録・一覧表示側の実装）
- I020: 学習統計画面の科目表示修正

## 背景/目的
- 現状、ユーザーに科目を紐づけるには管理者が `UserSubjectAccess` を直接操作するしかなく、ユーザー自身が科目を選択・変更する手段がない
- アカウント登録フローに科目選択ステップを追加し、登録後もユーザーが自分で科目の追加・削除を行えるようにする
- これにより「クイズを始める」などの機能でユーザーに紐づく科目が正しく表示されるようになる

## スコープ
### 含む
- アカウント登録フロー（RegisterページまたはWizard）への科目選択ステップ追加
- 登録時に選択した科目を `UserSubjectAccess` に保存するバックエンドAPI対応
- 登録後に科目を追加・削除できるUI（マイページ等）
- 科目追加・削除のバックエンドAPI（エンドポイントの追加または既存拡張）

### 含まない
- 管理者による科目割り当て機能
- 科目ごとの統計・進捗のリセット処理

## 受け入れ条件（Acceptance Criteria）
- [ ] アカウント登録時に組織の科目一覧から自分が学習する科目を選択できる
- [ ] 選択した科目が `UserSubjectAccess` に保存される
- [ ] 登録後にユーザーが科目を追加・削除できる画面（またはセクション）が存在する
- [ ] 「クイズを始める」の科目選択画面に、ユーザーが登録した科目のみ表示される

## 影響範囲（想定）
- Backend: 登録APIへの科目選択パラメータ追加、UserSubjectAccess CRUD API
- Frontend: 登録フロー（Register画面）への科目選択ステップ、マイページまたは設定画面への科目管理UI
- DB: なし（UserSubjectAccess テーブルは既存）
- Config/Infra: なし

## Danger Ops（有/無）
