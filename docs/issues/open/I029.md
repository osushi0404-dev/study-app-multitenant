# I029: Claude Code settings.json の allow 拡充と PostToolUse フック追加

## 関連資料
- docs/proposals/I026_ai_dev_improvement_proposal.md（改善案 A）

## 背景/目的
- `.claude/settings.json` の `permissions.allow` に未登録のコマンドが多く、日常的なワークフロー中に確認ダイアログが頻発している
- `git fetch`・`git branch --show-current` などの読み取り専用コマンドでも毎回ユーザー承認を求められ、スキル（/plan-issue・/close 等）が途中で止まる
- allow を拡充してユーザーの介入を「本当に重要な判断」のみに絞ることで、スキルが途切れなく動くようにする
- PostToolUse フックを追加し、ファイル編集後に自動で品質チェックが走る仕組みを整える

## スコープ
### 含む
- `git fetch *`・`git branch --show-current`・`git rev-parse --abbrev-ref HEAD`・`git push -u origin *` を allow に追加
- `Bash(python3 *)` を allow に追加（フック・スクリプトのテスト実行用）
- PostToolUse フック（Edit/Write 後の自動チェック）の設計・追加

### 含まない
- deny ルールの変更
- pretooluse_guard.py スクリプト本体の大幅改修
- npm / npx の allow 追加（Docker 外フロントエンド操作は現状不要のため除外）

## 受け入れ条件（Acceptance Criteria）
- [ ] `git fetch`・`git branch --show-current` 等が確認ダイアログなしで実行される
- [ ] `python3` スクリプトが確認ダイアログなしで実行される
- [ ] PostToolUse フックが Edit/Write 後に自動で動作する
- [ ] 既存の deny ルール・pretooluse_guard.py の動作が変わらない
- [ ] 設定変更後、主要スキル（/plan-issue・/close）を一通り動作確認できる

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: `.claude/settings.json`（Claude Code の権限設定）
