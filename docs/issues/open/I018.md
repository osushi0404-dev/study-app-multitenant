# I018: ESLint exhaustive-deps ルール有効化

## 関連資料
- I017 コードレビュー指摘（2026-04-01）

## 背景/目的
- `eslint-plugin-react-hooks` の `exhaustive-deps` ルールが現在無効（または未設定）になっている
- このルールが無効だと `useEffect` / `useCallback` / `useMemo` の依存配列の漏れが静的解析で検出されず、stale closure バグが埋め込まれやすい
- React 公式推奨・CRA デフォルトでもあり、有効化がモダン React 開発のベストプラクティス

## スコープ
### 含む
- ESLint 設定（`.eslintrc.*` または `package.json` の eslint セクション）で `react-hooks/exhaustive-deps` を `warn` または `error` に設定
- 有効化後に発生する既存の警告・エラーをすべて修正（または `// eslint-disable-next-line` で意図的抑制）

### 含まない
- ESLint 以外の lint ルール変更
- テストコードの lint 対応（必要であれば別イシュー）

## 受け入れ条件（Acceptance Criteria）
- [ ] `react-hooks/exhaustive-deps` が `warn` 以上で有効化されている
- [ ] `npm run lint`（または CI の Frontend Lint）がエラーなく通過する
- [ ] 既存コードの依存配列漏れがすべて修正または意図的に抑制されている

## 影響範囲（想定）
- Frontend: `.eslintrc.*` または `package.json`（ESLint 設定）
- Frontend: `useEffect` / `useCallback` / `useMemo` を使用している全コンポーネント（修正が必要な箇所は調査フェーズで特定）
- Backend: なし
- DB: なし
- Config/Infra: なし

## Danger Ops（有/無）
- 無
