# I058: コマンド化: plan-issue-review・code-review のオーケストレーションをシェルスクリプト化する

## 関連資料
- GitHub Issue: #119
- Draft PR: #120
- 起点: I057 振り返り・レビューシステム動作検証（2026-05-03）
- 設計議論: I054 サブエージェントレビュー設計（docs/plans/closed/plan_I054.md）

## 背景/目的
現行の `/plan-issue-review`・`/code-review` スキルは markdown を Claude が解釈して実行するため、
実行ごとに手順の解釈やぶれが生じる可能性がある。

**問題の構造**:
- 決定論的な操作（ファイル保存・PR 投稿・計画書リンク追記・判定案内）が prose で書かれており Claude の解釈に依存している
- サブエージェントの出力に `agentId`・`<usage>` などのシステムメタデータが混入し、verbatim 保存が厳密に守れない
- pre-commit フックが末尾スペース・末尾改行を修正するため、保存後に再ステージが必要になる

**解決策**:
オーケストレーション（制御フロー・副作用）をシェルスクリプトに移し、Claude は `claude -p` 経由で判断部分のみ担当する。

## スコープ
### 含む
- `scripts/claude/plan-issue-review.sh` の新規作成
- `scripts/claude/code-review.sh` の新規作成
- `.claude/skills/plan-issue-review/SKILL.md` を上記スクリプトを呼ぶ薄いラッパーに更新
- `.claude/skills/code-review/SKILL.md` を上記スクリプトを呼ぶ薄いラッパーに更新
- `.claude/review-agents/plan-reviewer.md`・`code-reviewer.md` へのツールアクセス制限追記（I058 retro C2 対応・判断ロジックは変更しない）
- `.claude/skills/test/SKILL.md` に「実施者: Claude」項目の自己実行ロジック追加（I058 retro で発見した /test スキルの不備を同一スコープで対応）
- `.claude/review-agents/plan-reviewer.md` の P4 セクションに CLI フラグ振る舞い検証チェック追加（I058 retro P1）
- `.claude/skills/implement/SKILL.md` にコードレビュー再実行ルール追加（Medium 以上 → 再レビュー・retro P2）
- `.pre-commit-config.yaml` に shellcheck フック追加（scripts/ 対象・retro P3）

### 含まない
- `plan-reviewer.md`・`code-reviewer.md` の判断ロジック変更
- `grill-me`・`plan-issue`・`retro` 等の対話系スキルのコマンド化
- CI/CD への自動組み込み
