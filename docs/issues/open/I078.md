# I078: 問題管理画面で正解選択肢の表示・編集保持に対応（is_correct write_only の見直し）

## 関連資料
- GitHub Issue: #156
- 起点: I073 振り返り（retro）の是正処置 C2 / plan_I073.md「retro carry-over 提案3」
- 発見経緯: I073 の手動テスト中にユーザーが指摘（参照で正解不可視・編集で正解ラジオ未選択）
- 前提イシュー（**hard 依存・先行必須**）: **I102（#192）問題管理を組織管理者権限に限定（非admin の問題 CRUD・参照を admin 限定・FE/BE 二重ガード）**。I102 が `ProblemViewSet` 全体を **read+write とも admin 限定**にする。これにより I078 は `ProblemViewSet.serializer_class` を is_correct 露出版（`ProblemAdminSerializer`）に**無条件で切り替えるだけ**でよい（read するのは admin だけなのでロール出し分け不要）。**順序制約: I102 を先に（または同時に）マージすること。** 逆順だと is_correct 無条件露出が I102 未適用の open read（`IsAuthenticated`）に漏れる。認可（`permission_classes`・`OrgAdminRoute`・`Layout` ナビ）は I102 が担当し、I078 では触らない。
- 調査: 出題前（`next_problem`）は `ProblemDisplaySerializer`→`ChoiceDisplaySerializer`（is_correct 非含有）。`ChoiceSerializer`（is_correct write_only）は管理用 `ProblemSerializer` と結果用 `QuizAnswerDetailSerializer` で共有。

## 背景/目的

### 現状の問題（証拠・再現手順）
問題管理画面（`frontend/src/pages/QuizManagement.tsx`）で、**正解の選択肢を確認・保持できない**:
1. **参照プレビュー**で正解選択肢がマークされない（A/B/C が並ぶだけで正解が分からない）。
2. **編集ダイアログ**を開いたとき、正解の選択肢のラジオが**初期選択されない**（全て未選択）。そのため編集のたびに正解を選び直す必要があり、選び忘れると保存時に「正解の選択肢を少なくとも1つ選択してください」で 400、あるいは**意図せず正解を取り違える**リスクがある（データ整合性リスク）。

再現: 画像/テキストを編集 → 編集ダイアログで正解ラジオが未選択 → そのまま保存しようとすると正解未指定で弾かれる、または別の選択肢を選んでしまう。

### 根本原因
`backend/problems/serializers.py` の `ChoiceSerializer` で `is_correct` が **`write_only=True`** に設定されており、**GET レスポンスに `is_correct` が含まれない**（出題画面で答えを漏らさないための設計）。このため、フロントは問題取得時に「どの選択肢が正解か」を知り得ず、参照プレビューでマークできず、編集ダイアログで正解ラジオを初期選択できない。`openEditDialog` は `is_correct: c.is_correct` を読むが、API が返さないため `undefined`（未選択）になる。

### 解決方針
**出題用・結果用・AI生成応答は `is_correct` を隠したまま（答え漏洩防止）**、**管理 `ProblemViewSet`（I102 で admin 限定）にだけ専用シリアライザで `is_correct` を返す**ように分離し、フロントで正解の表示・編集初期選択・保持を実装する。認可の是正（read+write admin 限定・`OrgAdminRoute`）は前提イシュー **I102（#192）** が担当（hard 依存・先行必須）。
- バックエンド: **管理専用 `ProblemAdminSerializer`（is_correct を露出する管理専用 Choice シリアライザを内包・is_correct は読み書き両可）を新設**（既存 `ProblemSerializer` を継承し `choices` フィールドのみ差し替え）。`ProblemViewSet.serializer_class` を **無条件で `ProblemAdminSerializer` に切り替える**（I102 で read が admin 限定になるため、ロール出し分けは不要）。**既存 `ProblemSerializer`・共有 `ChoiceSerializer` は is_correct 非露出のまま不変更**（`QuizAnswerDetailSerializer.problem`・`generate_ai`/`generate_adaptive` 応答経路への波及を避ける＝これらは `role='user'` が到達し得るため）。出題用（`ProblemDisplaySerializer`→`ChoiceDisplaySerializer`）も非返却のまま。**認可（`permission_classes`）・FE ガードは変更しない（I102 の担当）。**
- フロント: 参照プレビューで正解選択肢を**チェックアイコン＋「正解」ラベル（緑系・色のみ非依存）**でマーク表示。編集ダイアログで正解ラジオを初期選択（`single_choice`/`multiple_choice` 両対応）し、保存時は現行どおりラジオ状態を送信（差分保存）。
