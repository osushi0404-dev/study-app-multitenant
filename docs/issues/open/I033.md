# I033: GitHub Projects カンバンと Milestones（Phase 1〜3）の設定

## 関連資料
- docs/proposals/I026_ai_dev_improvement_proposal.md（改善案 J）
- GitHub Issue: #76

## 背景/目的
- 改善イシュー（I029〜I036）の進捗が一目でわからない状態
- GitHub Projects ボードと Milestones を設定することで、改善フェーズの進捗を可視化する

## スコープ
### 含む
- `gh` CLI で Milestones 3件（Phase 1〜3）を作成
- GitHub Projects ボードを作成し各改善イシューを登録

Milestones（案）:
- Phase 1: settings.json 改善・Dependabot・PR テンプレート（I028・I029）
- Phase 2: GitHub MCP・採番ロジック修正・Branch protection・Projects・pre-commit（I030〜I034）
- Phase 3: Sequential Thinking・Web Search MCP・/retro 推奨化（I035・I036）

### 含まない
- Projects の自動化ルール設定（issue クローズ時の自動移動等）

## 受け入れ条件（Acceptance Criteria）
- [ ] Milestones 3件（Phase 1〜3）が GitHub 上に作成されている
- [ ] 各改善イシューが対応する Milestone に紐づいている
- [ ] GitHub Projects ボードが作成され、改善イシューが登録されている

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: GitHub リポジトリの Projects・Milestones

## Danger Ops（有/無）
- 無
