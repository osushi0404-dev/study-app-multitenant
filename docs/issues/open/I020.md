# I020: 学習統計画面：組織登録済み全科目を表示するよう修正

## 関連資料
- I017: 科目管理画面UX刷新（科目管理側の実装）

## 背景/目的
- 現状、学習統計画面に表示される科目一覧は `UserSubjectAccess`（ユーザーが登録時に選択した科目）に基づいてフィルタリングされている
- 正しい仕様は「アカウントが所属する組織が登録している全科目を表示する」であるため、修正が必要

## スコープ
### 含む
- 学習統計画面の科目一覧をユーザーの `UserSubjectAccess` ではなく組織登録済み全科目から取得するよう変更
- バックエンドAPIの修正（必要な場合）
- フロントエンドの修正（必要な場合）

### 含まない
- 科目ごとの統計表示ロジックの変更
- ユーザーへの科目割り当て機能（別イシューで対応）

## 受け入れ条件（Acceptance Criteria）
- [ ] 学習統計画面に、組織に登録されているすべての科目が表示される
- [ ] `UserSubjectAccess` に登録されていない科目も表示対象となる
- [ ] 管理者が科目管理画面から追加した科目が即座に統計画面に反映される

## 影響範囲（想定）
- Backend: 学習統計用のViewまたはSerializerで使用するクエリの修正
- Frontend: 学習統計画面のAPIコールまたはデータ表示ロジック
- DB: なし
- Config/Infra: なし

## Danger Ops（有/無）
- 無
