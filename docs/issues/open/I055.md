# I055: pre-commit に静的チェックを追加し npm audit を CI に組み込んでコード品質・依存関係セキュリティを自動保証する

## 関連資料
- 提案資料: docs/proposals/automation_over_manual_checks_proposal.md（イシュー①）
- GitHub Issue: #114
- Draft PR: #115

## 背景/目的
- 現在 flake8・bandit・ESLint・TypeScript 型チェックは CI で自動実行されているが、pre-commit フックには含まれていないため「コミット前に手動実行してください」という手順がスキルファイルに残っている
- npm audit は CI に未設定・手動実行ルールのみ存在し、フロントエンド依存関係セキュリティが自動保証されていない
- Python 依存関係脆弱性スキャン（pip-audit）は手動手順すら存在しない空白地帯になっている
- `detect-secrets` はデフォルトで JWT パターンを検出しないギャップがある
- これらを自動化することで、Claude の手動 lint 実行コストを削減し、機械的チェックをツールに委譲する

## スコープ
### 含む
- `.pre-commit-config.yaml` に flake8（または Ruff）/ bandit / ESLint フックを追加
- `bandit` の除外設定を `backend/setup.cfg` に `[bandit]` セクションとして切り出し（CI と pre-commit で設定を共有）
- CI の `frontend-lint` ジョブに `npm audit --audit-level=critical --omit=dev` を追加（`high` は react-scripts のトランザクティブ依存で恒常的に発生し修正不可のため `critical` を閾値とする。/grill-me で確定）
- CI の `backend-lint` ジョブに `pip-audit` を追加（`backend/requirements-dev.txt` に追記）
- `detect-secrets` の JWT 検出ギャップを確認し、必要であれば `JwtTokenDetector` を追加
- `/implement` SKILL.md 手順2 の手動 lint・audit 実行指示を「pre-commit と CI が自動実行」に書き換え
- `docs/runbooks/pre-commit.md` のフック一覧を更新
- コーディング規約ドキュメント（`rules/` 配下）に「linter が自動チェック」vs「手動確認」の区分を明示

### 含まない
- flake8 → Ruff への移行（ツール選定は実装前にユーザーと確認・別途対応）
- `npm audit` の unfixable 例外管理方針の決定（チーム判断が必要なため方針決定後に対応）
- mypy の CI 追加
- GitHub Actions SHA ピン固定・`permissions:` 設定

## 受け入れ条件（Acceptance Criteria）
- [ ] `git commit` 時に flake8（または Ruff）/ bandit / ESLint が自動実行され、エラーがあればコミットがブロックされる
- [ ] CI の `frontend-lint` ジョブで `npm audit --audit-level=critical` が実行される（high は react-scripts 問題で修正不可のため critical 閾値）
- [ ] CI の `backend-lint` ジョブで `pip-audit` が実行される
- [ ] bandit の除外設定が `backend/setup.cfg` に集約され、CI の CLI 引数と一致している
- [ ] `detect-secrets` の JWT 検出状況を確認し、対応方針（追加 or 不要）を記録している
- [ ] `/implement` SKILL.md 手順2 から手動 lint・audit の実行指示が削除または「pre-commit / CI が自動実行」に書き換えられている
- [ ] `docs/runbooks/pre-commit.md` のフック一覧が最新の状態に更新されている
- [ ] コーディング規約ドキュメントに linter / 手動確認の区分が明示されている
- [ ] CI の全ジョブが pass する

## 影響範囲（想定）
- Backend: `backend/setup.cfg`（bandit 設定追加）、`backend/requirements-dev.txt`（pip-audit 追加）
- Frontend: `frontend/package.json`（npm audit ステップ確認）
- Config/Infra: `.pre-commit-config.yaml`、`.github/workflows/ci.yml`、`.claude/skills/implement/SKILL.md`、`docs/runbooks/pre-commit.md`、`rules/` 配下ドキュメント
- DB: なし
