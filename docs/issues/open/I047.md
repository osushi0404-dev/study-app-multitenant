# I047: 計画書作成・実装スキルを8観点フレームワークに整合させる

## 関連資料
- 提案ドキュメント: docs/proposals/review_perspective_framework.md（8観点フレームワーク全体）
- GitHub Issue: #96
- 前提イシュー: I045（P3・P5・P8 レビュー側追加）、I046（P1・P2・P4・P6・P7 レビュー側補完）

## 背景/目的
I045・I046 でレビュースキル（`/plan-issue-review`・`/code-review`）を8観点フレームワークに整合させた。
しかし上流スキル（`/plan-issue`・`/grill-me`・`/implement`）は更新されていないため、
「作る段階では意識されない → レビューで多発修正」という非対称が生まれている。

上流スキルにも同じ8観点の視点を組み込むことで、問題をレビュー前の段階で防止し、fix-loop の発生を減らす。

対象スキルと追加内容の方針:
- `/grill-me`: P3・P5・P8 に関する設計確認質問を追加する（トランザクション境界・ログ設計・リリース方式・コスト等）
- `/plan-issue`: 計画書テンプレートに P3（データ整合性リスク）・P5（運用設計）・P8（コスト・保守見積もり）の設計セクションを追加する
- `/implement`: 実装前チェックリストに P3（ForeignKey削除挙動・インデックス）・P5（ログ・タイムアウト）の確認を追加する

## スコープ
### 含む
- `/grill-me` に P3・P5・P8 に関する設計確認観点を追加する
- `/plan-issue` の計画書テンプレート・承認前チェックリストに P3・P5・P8 の設計確認を追加する
- `/implement` の実装チェックリストに P3・P5 の実装確認を追加する

### 含まない
- レビュースキルの変更（→ I045・I046）
- P1・P2・P4・P6・P7 の上流追加（I045・I046 の運用実績を見てから判断する）
- 新スキルの新設

## 受け入れ条件（Acceptance Criteria）
- [ ] `/grill-me` に P3・P5・P8 の設計確認観点が追加されている
- [ ] `/plan-issue` の計画書テンプレートに P3・P5・P8 のセクションが追加されている
- [ ] `/implement` の実装チェックリストに P3・P5 の確認項目が追加されている
- [ ] 追加内容が I045・I046 で整備したレビュー観点と対応している（上流・下流で同じ観点を参照できる）
- [ ] 既存のスキル指示文と矛盾・重複がない

## 影響範囲（想定）
