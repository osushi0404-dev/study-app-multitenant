## 背景/目的

**背景**: I179（PR #300）の `/code-review` を実行したところ、CI の「Backend Lint & Security」ジョブの `pip-audit -r requirements.txt` が失敗した。I179 は `backend/`・依存ファイルを変更していない。develop の CI は 2026-10-20 11:53（UTC）まで成功しており、その後に Pillow 12.3.0 の脆弱性が公開されたことが原因。同じ requirements.txt を使うすべての PR・develop で同じ失敗が起きる。
**目的**: Pillow を脆弱性の修正版（13.0.0）に更新し、`pip-audit` が通る状態に戻す。画像のアップロード検証が更新後も同じように動くことを確認する。

### 現状の問題（証拠・再現手順）
- 再現: `backend/` で `pip-audit -r requirements.txt`
- 結果（CI・2026-10-20T23:55Z）: `Found 8 known vulnerabilities in 1 package`
  ```
  pillow 12.3.0  CVE-2026-112895 13.0.0
  pillow 12.3.0  CVE-2026-112400 13.0.0
  pillow 12.3.0  CVE-2026-112397 13.0.0
  pillow 12.3.0  CVE-2026-112896 13.0.0
  pillow 12.3.0  CVE-2026-112897 13.0.0
  pillow 12.3.0  CVE-2026-112395 13.0.0
  pillow 12.3.0  CVE-2026-112404 13.0.0
  pillow 12.3.0  CVE-2026-112899 13.0.0
  ```
- `backend/requirements.txt` 8 行目: `Pillow==12.3.0`

### 根本原因
固定している Pillow 12.3.0 に、新しい脆弱性 8 件が公開された。修正版は 13.0.0 のみ（12.x 系の修正版は pip-audit の Fix Versions に無い）。

### 解決方針
`backend/requirements.txt` の `Pillow==12.3.0` を `Pillow==13.0.0` に更新する。メジャー更新のため、Pillow を使う箇所（下記）と Docker イメージのビルドを確認する。各 CVE の内容（どの画像形式・どの処理に影響するか）は計画時に確認し、アップロード検証（`Image.open` で画像サイズを読む）への影響を評価する。あわせて、アップロード検証の Pillow 依存分岐に再発防止テストを追加する（設計確認メモ参照）。
