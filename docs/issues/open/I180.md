# I180: Pillow を 13.0.0 に更新（既知脆弱性 8 件の解消）

## 関連資料
- GitHub Issue: #301
- CI の失敗ログ（PR #300・I179）: https://github.com/osushi0404-dev/study-app-multitenant/actions/runs/39518014430/job/118954739270
- 依存監査の運用: `docs/runbooks/dependency-audit.md`

## 背景/目的

**背景**: I179（PR #300）の `/code-review` を実行したところ、CI の「Backend Lint & Security」ジョブの `pip-audit -r requirements.txt` が失敗した。I179 は `backend/`・依存ファイルを変更していない。develop の CI は 2026-10-20 11:53（UTC）まで成功しており、その後に Pillow 12.3.0 の脆弱性が公開されたことが原因。同じ requirements.txt を使うすべての PR・develop で同じ失敗が起きる。
**目的**: Pillow を脆弱性の修正版（13.0.0）に更新し、`pip-audit` が通る状態に戻す。画像のアップロード検証が更新後も同じように動くことを確認する。

### 現状の問題（証拠・再現手順）
- 再現: `backend/` で `pip-audit -r requirements.txt`
- 結果（CI・2026-10-20T23:55Z）: `Found 8 known vulnerabilities in 1 package`
  ```
  pillow 12.3.0  CVE-2026-112895 13.0.0
  pillow 12.3.0  CVE-2026-112400 13.0.0
  pillow 12.3.0  CVE-2026-112397 13.0.0
  pillow 12.3.0  CVE-2026-112896 13.0.0
  pillow 12.3.0  CVE-2026-112897 13.0.0
  pillow 12.3.0  CVE-2026-112395 13.0.0
  pillow 12.3.0  CVE-2026-112404 13.0.0
  pillow 12.3.0  CVE-2026-112899 13.0.0
  ```
- `backend/requirements.txt` 8 行目: `Pillow==12.3.0`

### 根本原因
固定している Pillow 12.3.0 に、新しい脆弱性 8 件が公開された。修正版は 13.0.0 のみ（12.x 系の修正版は pip-audit の Fix Versions に無い）。

### 解決方針
`backend/requirements.txt` の `Pillow==12.3.0` を `Pillow==13.0.0` に更新する。メジャー更新のため、Pillow を使う箇所（下記）と Docker イメージのビルドを確認する。各 CVE の内容（どの画像形式・どの処理に影響するか）は計画時に確認し、アップロード検証（`Image.open` で画像サイズを読む）への影響を評価する。

## 実装対象（既知のもの）
| ファイル | 変更内容 |
|---------|---------|
| `backend/requirements.txt` | `Pillow==12.3.0` → `Pillow==13.0.0` |
| `backend/problems/utils.py`（82 行目 `Image.open(file)`・`image.size`） | 変更不要の見込み。13.0.0 の非互換変更に当たらないか確認する |
| `backend/problems/tests/test_I073_image_update.py`（`Image.new(...).save(buf, format="PNG")`） | 変更不要の見込み。更新後に通ることを確認する |

Pillow の利用箇所は `git grep -n -i -E "from PIL|import PIL|pillow|ImageField" -- backend` で全件確認済み（上の 2 ファイルのほかは `backend/problems/migrations/0008_add_problem_images.py` の `ImageField` だけで、これは 0009 で `CharField` に変更済みの過去のマイグレーション）。

## スコープ
### 含む
- Pillow 13.0.0 への更新と、Pillow を使う箇所の互換性確認（既存テストの実行・Docker イメージの再ビルド）
- 13.0.0 のリリースノートで非互換変更を確認し、記録する
### 含まない
- Pillow 以外の依存の更新（pip-audit が他の脆弱性を出した場合は別イシュー）
- 画像処理の機能追加・仕様変更

## 関連する品質基準
- C1 セキュリティ — 画像アップロードはユーザー入力を Pillow で開くため、既知の脆弱性を残さない

## 受け入れ条件（Acceptance Criteria）
- [ ] `backend/requirements.txt` が `Pillow==13.0.0` になっている
- [ ] `backend/` で `pip-audit -r requirements.txt` が exit 0（既知の脆弱性 0 件）
- [ ] backend の Docker イメージが再ビルドでき、コンテナ内で `python -c "import PIL; print(PIL.__version__)"` が `13.0.0` を出す

- DB: なし
- Config/Infra: backend の Docker イメージの再ビルド（`backend/Dockerfile` は `python:3.11-slim`。変更不要の見込み）
