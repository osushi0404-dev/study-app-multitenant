# I032: GitHub Branch protection rules 設定手順書の作成と適用

## 関連資料
- docs/proposals/I026_ai_dev_improvement_proposal.md（改善案 I）
- GitHub Issue: #73
- Draft PR: #74

## 背景/目的

**背景**: 直 push のブロックが Claude Code 経由の deny ルールと hook のみで、GitHub Web UI・他ツール経由の push を防げていなかった（I026 改善提案 I）。
**目的**: Branch protection rules の設定手順書を作成・適用し、GitHub 側でも直 push と CI 未通過マージを物理的に防ぐ二重ガードを確立する。

- 現状、直 push のブロックは `.claude/settings.json` の deny ルールと `pretooluse_guard.py` のみで行っており、Claude Code 経由の操作のみが対象
- GitHub Web UI・他ツール経由の push は防止できていない
- Branch protection rules を設定することで GitHub 側でも物理的に防止できる二重ガードになる

## スコープ
### 含む
- `develop`・`main` ブランチへの Branch protection rules 設定手順書を Claude が作成
- ユーザーが GitHub Settings 画面で適用
- 設定内容: Require PR before merging・Require status checks to pass・Do not allow bypassing

### 含まない
- main の保護ルール緩和（リリース時フローへの影響は別途確認）
- GitHub Actions による自動化

## 受け入れ条件（Acceptance Criteria）
- [ ] 手順書が `docs/` 配下に作成されている
- [ ] ユーザーが手順書に従って `develop`・`main` に Branch protection rules を適用している
- [ ] 直 push が GitHub 側でもブロックされることを確認している
- [ ] CI が通らない状態でのマージが GitHub 側でブロックされることを確認している

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: GitHub リポジトリ Settings（ユーザーが操作）

## Danger Ops（有/無）
- 無（設定追加のみ。既存 PR への影響はない）
