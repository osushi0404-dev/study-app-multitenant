# I035: Sequential Thinking・Web Search MCP の評価と導入

## 関連資料
- docs/proposals/I026_ai_dev_improvement_proposal.md（改善案 D）
- GitHub Issue: #79

## 背景/目的
- Sequential Thinking MCP: 複雑な問題（DB スキーマ変更・認証フロー設計等）で推論過程を構造化し、計画立案品質を向上させる
- Web Search MCP: Claude の知識カットオフ（2025年8月）以降の情報（最新ライブラリバージョン・CVE 等）をリアルタイムで参照できるようにする
- `/plan-issue`・`/fix-loop` フェーズの品質向上が期待される

## スコープ
### 含む
- 各 MCP の動作確認・効果測定
- 有効と判断した MCP の設定ファイルへの追加
- 利用場面の runbook への記載

### 含まない
- GitHub MCP（I030 で実施）

## 受け入れ条件（Acceptance Criteria）
- [ ] Sequential Thinking MCP の動作確認ができている（または導入不要と判断した根拠が記録されている）
- [ ] Web Search MCP の動作確認ができている（または導入不要と判断した根拠が記録されている）
- [ ] 導入した MCP の設定が `.claude/` 配下に追加されている
- [ ] 利用場面が runbook に記載されている

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: `.claude/` 配下に MCP 設定追加（有効と判断した場合）

## Danger Ops（有/無）
