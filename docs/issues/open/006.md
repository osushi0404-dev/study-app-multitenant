# I006: backend/media をリポジトリに含める

## 背景/目的
- 現在 `backend/media/` は `.gitignore` によりリポジトリから除外されている
- メディアファイル（アップロード画像等）が開発環境間で共有されず、セットアップ時に手動配置が必要
- サンプル・初期データとして必要なメディアファイルをリポジトリに含め、開発環境の再現性を高める

## スコープ
### 含む
- `.gitignore` から `backend/media/` の除外設定を削除
- `backend/media/` ディレクトリをリポジトリに追加（`.gitkeep` または既存ファイル）

### 含まない
- ユーザーがアップロードした本番データのコミット
- メディアストレージ設定の変更（S3移行等）

## 受け入れ条件（Acceptance Criteria）
- [ ] `.gitignore` から `backend/media/` の除外エントリが削除されている
- [ ] `backend/media/` ディレクトリが git 管理下に入っている
- [ ] `git clone` 後に `backend/media/` が存在する

## 影響範囲（想定）
- Backend: `.gitignore` 変更のみ
- Frontend: なし
- DB: なし
- Config/Infra: なし

## Danger Ops（有/無）
- 無
