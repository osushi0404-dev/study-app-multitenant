# I006: 企業・団体ごとの科目追加機能（アコーディオン UI）

## 背景/目的
- 現状、科目（Subject）はシステム全体で管理されており、企業・団体（Organization）ごとに科目を追加する手段がない
- 管理者が問題管理画面から、組織ごとに科目を追加できるようにすることで、マルチテナント運用を強化する

## スコープ
### 含む
- 問題管理画面（または問題管理メニュー配下）に、企業・団体ごとのアコーディオン UI を追加
- アコーディオン内に「科目追加」フォームを配置（科目名入力 → 保存）
- バックエンド：組織に紐づく科目を作成する API エンドポイント
- フロントエンド：アコーディオン展開 → フォーム入力 → 保存 → 一覧更新
- 科目追加時に以下のフォルダを自動作成
  - `backend/media/org/{org_slug}/subjects/{subject_slug}/problem/`
  - `backend/media/org/{org_slug}/subjects/{subject_slug}/explanation/`

### 含まない
- 科目の編集・削除機能（別イシューで対応）
- 科目のソート・並び替え
- 一般ユーザー向けの科目追加 UI

## 受け入れ条件（Acceptance Criteria）
- [ ] 問題管理画面に企業・団体一覧がアコーディオン形式で表示される
- [ ] アコーディオンを展開すると、その組織に紐づく科目一覧と「科目追加」フォームが表示される
- [ ] 科目名を入力して保存すると、その組織の科目として登録される
- [ ] 保存後、科目一覧が即時更新される
- [ ] 科目追加時に `problem/` と `explanation/` フォルダが自動作成される
- [ ] 既存の科目管理・問題管理の動作に影響がない

## 影響範囲（想定）
- Backend: subjects / organizations 関連 API（新規エンドポイントまたは既存拡張）
- Frontend: 問題管理画面コンポーネント（アコーディオン追加）
- DB: 既存の Subject モデルに organization_id が紐づいていれば変更なし、なければ要確認
- Config/Infra: なし

## Danger Ops（有/無）
- 無
