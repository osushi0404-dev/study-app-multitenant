# I023: /fix-loop・/plan-issue スキルの品質向上：セキュリティ・ベストプラクティス観点での手順強化と関連ドキュメント更新

## 関連資料
- `.claude/skills/fix-loop/SKILL.md`
- `.claude/skills/plan-issue/SKILL.md`
- `docs/runbooks/workflow.md`
- `docs/work/open/` 配下のワークフロードキュメント

## 背景/目的
- `/fix-loop` スキルは失敗時の修正フローを定義しているが、対応案の提示基準にセキュリティ・ベストプラクティス・モダン開発の評価軸が含まれていない
- `/plan-issue` スキルも同様に、計画立案時のセキュリティ・品質観点のチェックが明示されていない
- 両スキルを改善し、生成される計画書・テストケース・レビュー文書・ワークフロー等の関連ドキュメントとの整合性も保つ

## スコープ
### 含む
- `.claude/skills/fix-loop/SKILL.md` の手順改善
  - 対応案提示にセキュリティ・ベストプラクティス・モダン開発の評価軸を追加
  - 修正後チェックリスト（型チェック・リント・セキュリティスキャン等）の追加
  - 根本原因分析にセキュリティ視点を追加
- `.claude/skills/plan-issue/SKILL.md` の手順改善
  - 計画立案時のセキュリティ・ベストプラクティス観点のチェック追加
  - 設計判断の評価基準の明確化
- 関連ドキュメントの更新（必要に応じて）
  - `docs/runbooks/workflow.md`
  - `docs/work/open/` 配下のワークフロー文書
  - 計画書テンプレート・テストケーステンプレート等

### 含まない
- 上記以外のスキル（`/implement`, `/code-review` 等）の変更
- バックエンド・フロントエンドのコード変更

## 受け入れ条件（Acceptance Criteria）
- [ ] `/fix-loop` スキルの対応案提示ステップに、セキュリティ・ベストプラクティス・モダン開発の評価軸が明記されている
- [ ] `/fix-loop` の修正後確認ステップにセキュリティスキャン・型チェック・リントが含まれている
- [ ] `/plan-issue` スキルの計画立案ステップにセキュリティ・ベストプラクティス観点のチェックが追加されている
- [ ] スキル内容と整合するよう、必要なワークフロードキュメントが更新されている
- [ ] スキル・ドキュメントの変更内容がレビュー・テスト文書に記録されている

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: `.claude/skills/` 配下スキルファイル、`docs/` 配下ドキュメント

## Danger Ops（有/無）
- 無
