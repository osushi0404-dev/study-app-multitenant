# I010: 科目管理画面の独立 — 問題管理画面から切り離し、左メニューに追加

## 背景/目的
- I006 で実装した科目追加機能は問題管理画面内のアコーディオン UI として配置されている
- 問題管理画面に科目管理が混在しており、UX が悪い（アコーディオンの開閉が煩雑）
- **機能はそのままに**、科目管理を独立した画面として切り出し、左サイドメニューから直接アクセスできるようにする（UX 改善のみ）

## 既存機能（移動対象・変更しない）
I006 で実装済みの以下の機能を、画面を変えてそのまま移植する。

- 組織（Organization）ごとの科目一覧表示
- 科目名入力フォーム → 保存（組織に紐づく科目を API で作成）
- 保存後の科目一覧即時更新
- 科目追加時のフォルダ自動作成（`backend/media/org/{org_slug}/subjects/{subject_slug}/problem/` と `explanation/`）

### 権限（変更しない）
- 科目管理画面・メニュー項目は `role='admin'`（組織管理者）のみ表示
- `role='user'`（一般ユーザー）には非表示
- バックエンドの科目追加 API も `IsOrgAdmin` パーミッションで保護済み（変更なし）

## スコープ
### 含む
- 左サイドメニューに「科目管理」メニュー項目を追加
- 科目管理専用画面（ルート）を新規作成
- 問題管理画面からアコーディオン UI（科目追加フォーム）を削除
- 科目一覧・追加機能を新しい科目管理画面に移動

### 含まない
- 科目追加以外の機能変更（既存機能はそのまま維持）
- 科目の編集・削除機能（別イシューで対応予定）
- 科目のソート・並び替え
- バックエンド API の変更（既存 API をそのまま使用）

## 受け入れ条件（Acceptance Criteria）
- [ ] 左サイドメニューに「科目管理」が表示される
- [ ] 「科目管理」リンクから専用画面に遷移できる
- [ ] 科目管理画面に組織ごとの科目一覧が表示される
- [ ] 科目管理画面から科目を追加できる（既存 API を使用）
- [ ] 科目追加後、一覧が即時更新される
- [ ] 問題管理画面からアコーディオン UI が削除されている
- [ ] 既存の問題管理・科目管理の動作に影響がない

## 影響範囲（想定）
- Backend: なし（既存 API をそのまま使用）
- Frontend: サイドメニュー、ルーティング、問題管理画面コンポーネント、新規科目管理画面
- DB: なし
- Config/Infra: なし

## Danger Ops（有/無）
- 無
