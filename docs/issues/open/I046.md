# I046: レビュースキルの観点を8観点フレームワークに全面整合させる

## 関連資料
- 提案ドキュメント: docs/proposals/review_perspective_framework.md（P1・P2・P4・P6・P7 の詳細確認項目）
- GitHub Issue: #95
- 前提イシュー: I045（P3・P5・P8 追加、先に完了させること）

## 背景/目的
I045 でゼロカバー観点（P3・P5・P8）を追加した後、部分カバー観点の不足項目を補完する。

現行の `/plan-issue-review` および `/code-review` で部分的にしかカバーされていない観点:
- **P1（要件適合性・業務ロジックの正しさ）**: 仕様追加検出・エッジケース確認が不足
- **P2（セキュリティ）**: JWT/セッション管理・レート制限対象・監査ログ等が不足
- **P4（テスト妥当性・回帰防止）**: 認可テスト・テスト独立性の確認が不足
- **P6（性能・UX・アクセシビリティ）**: エラーメッセージ・フォーカス管理等が不足
- **P7（設計・実装品質）**: 命名一貫性・アンチパターン具体例等が不足

これらを補完し、8観点フレームワークへの全面整合を完了させる。

## スコープ
### 含む
- `/plan-issue-review` に P1・P2・P4・P6・P7 の不足確認項目を追加する
- `/code-review` に P1・P2・P4・P6・P7 の不足確認項目を追加する
- 重大度定義（Blocker/High/Medium/Low）は既存定義を踏襲する

### 含まない
- P3・P5・P8 の追加（→ I045）
- `/plan-issue`・`/grill-me`・`/implement` の上流スキル更新（→ I047）
- 新スキルの新設

## 受け入れ条件（Acceptance Criteria）
- [ ] `/plan-issue-review` の確認項目に P1・P2・P4・P6・P7 の不足項目が追加されている
- [ ] `/code-review` の確認項目に P1・P2・P4・P6・P7 の不足項目が追加されている
- [ ] proposals の詳細確認項目と追加内容が一致している
- [ ] 既存の確認項目と重複・矛盾がない
- [ ] I045 で追加した P3・P5・P8 観点と境界が明確に区別されている
