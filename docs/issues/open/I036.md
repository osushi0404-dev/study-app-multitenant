# I036: workflow.md の /retro 推奨化

## 関連資料
- docs/proposals/I026_ai_dev_improvement_proposal.md（改善案 E）

## 背景/目的
- `docs/runbooks/workflow.md` で `/retro` が「任意」扱いのため、テスト OK 後に省略されるケースがある可能性がある
- 振り返りを実施しないと問題が蓄積し、同じ失敗が繰り返されるリスクがある
- 「推奨（テスト OK 後は原則実施）」に変更して継続的改善サイクルを確立する

## スコープ
### 含む
- `docs/runbooks/workflow.md` の `/retro` の扱いを「任意」→「推奨（テスト OK 後は原則実施）」に変更
- CLAUDE.md のスキル説明の `/retro` 箇所も同様に更新（必要な場合）

### 含まない
- `/retro` スキル本体の変更

## 受け入れ条件（Acceptance Criteria）
- [ ] `workflow.md` の `/retro` が「推奨（テスト OK 後は原則実施）」として記載されている
- [ ] 省略可能なケース（小規模修正等）の基準が明記されている（任意判断の余地を残す場合）

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: `docs/runbooks/workflow.md` のみ

## Danger Ops（有/無）
- 無
