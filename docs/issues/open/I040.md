# I040: /plan-issue に設計インタビュー（Grill Me）フェーズを追加する

## 関連資料
- 参考記事: https://x.com/L_go_mrk/status/2040032952818729206（Grill Me スキルの解説）
- GitHub Issue: #84
- Draft PR: #86

## 背景/目的
現在の `/plan-issue` スキルは、イシューファイルを読んで即座に計画書を作成する。
設計上の曖昧な点を Claude が「平均的な判断」で埋めてしまうリスクがあり、
それが `/fix-loop` 発生の上流原因になりうる。

Grill Me フェーズを計画書作成前に挿入することで、
設計認識のギャップを実装前に解消し、計画書の質を上流から担保する。

## スコープ
### 含む
- 独立スキル `/grill-me` の新規作成（`.claude/skills/grill-me/SKILL.md`）
  - イシューファイルを読み込み、設計上の曖昧な点を番号付きリストで一括提示する
  - ユーザーの回答をイシューファイルの「設計確認メモ」セクションに追記する
- `workflow.md` への `/grill-me` スキル追記（スキル一覧・フロー図・移行テーブル）

### 含まない
- `/plan-issue` スキルの変更
- 他のスキル（`/implement` 等）の変更
- `plan-writing-rules.md` の変更（別イシューで対応）

## 受け入れ条件（Acceptance Criteria）
- [ ] `/grill-me I###` を実行すると、イシューの設計上の曖昧な点が番号付きリストで提示される
- [ ] 質問はコードベース探索で自己解決できる疑問を除いた「本当に曖昧な点」に絞られている
- [ ] 質問がゼロの場合は「設計上の疑問点はありませんでした。」を表示してスキップする
- [ ] ユーザーの回答を受けて、イシューファイルの「設計確認メモ」に回答内容が追記される
- [ ] `workflow.md` に `/grill-me` がスキルとして追記され、フロー図に組み込まれている

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra:
  - `.claude/skills/grill-me/SKILL.md`（新規作成）
  - `docs/runbooks/workflow.md`（スキル一覧・フロー図に追記）
