# I040: /plan-issue に設計インタビュー（Grill Me）フェーズを追加する

## 関連資料
- 参考記事: https://x.com/L_go_mrk/status/2040032952818729206（Grill Me スキルの解説）
- GitHub Issue: #84

## 背景/目的
現在の `/plan-issue` スキルは、イシューファイルを読んで即座に計画書を作成する。
設計上の曖昧な点を Claude が「平均的な判断」で埋めてしまうリスクがあり、
それが `/fix-loop` 発生の上流原因になりうる。

Grill Me フェーズを計画書作成前に挿入することで、
設計認識のギャップを実装前に解消し、計画書の質を上流から担保する。

## スコープ
### 含む
- `/plan-issue` スキルへの設計インタビューフェーズの追加
  - イシューファイルを読み込み、設計上の曖昧な点を質問として列挙する
  - ユーザーの回答を踏まえて計画書を作成する
- `workflow.md` への `/plan-issue` 動作説明の更新（必要な場合）

### 含まない
- 他のスキル（`/implement` 等）の変更
- `plan-writing-rules.md` の変更（別イシューで対応）

## 受け入れ条件（Acceptance Criteria）
- [ ] `/plan-issue I###` 実行時、計画書作成前に設計質問のフェーズが入る
- [ ] 質問はコードベースを探索したうえで、本当に曖昧な点に絞られている
- [ ] ユーザーが回答した内容が計画書に反映されている
- [ ] 質問が不要なほどイシューが詳細な場合はスキップできる（過剰な質問の強制なし）

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: `.claude/skills/plan-issue`（スキルファイル）
