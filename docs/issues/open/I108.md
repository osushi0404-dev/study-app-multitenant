# I108: Pillow 12.3.0 へのセキュリティアップデート（pip-audit CI ブロッカー解消）

## 関連資料
- GitHub Issue: #203
- 失敗 CI 実行: https://github.com/osushi0404-dev/study-app-multitenant/actions/runs/29349369205/job/87141342050（PR #202 / Backend Lint & Security）
- 発見経緯: I107 の /code-review 前 CI ゲートで検出（I107 の差分とは無関係）

## 背景/目的

### 現状の問題（証拠・再現手順）
- CI の Backend Lint & Security ジョブ内 `pip-audit -r requirements.txt` が exit 1 で失敗し、**全 PR の CI がブロック**されている（/code-review スクリプトは CI 失敗時にレビューを開始しない）。
- 検出内容（2026-07-14 の PR #202 CI 実行ログより）: `Pillow 12.2.0` に既知脆弱性 **5件** — PYSEC-2026-2253 / 2254 / 2255 / 2256 / 2257。すべて Fix Version は **12.3.0**。
- `backend/requirements.txt` の現在のピン: `Pillow==12.2.0`（grep で確認済み）。
- develop の最終 CI（2026-07-09、PR #194/#195 マージ時）は成功しており、これらの CVE は 2026-07-09〜07-14 の間に公開されたもの。リポジトリ側の変更なしに発生した環境ドリフトであり、以後どのブランチの PR でも再現する。

### 根本原因
- 依存ライブラリ Pillow のピン版（12.2.0）に対して新規 CVE が公開され、CI の pip-audit ゲート（既知脆弱性ゼロを要求）に抵触した。コードの不具合ではなく、セキュリティゲートが設計どおり動作した結果の依存更新要求。

### 解決方針
- `backend/requirements.txt` の `Pillow==12.2.0` を `Pillow==12.3.0`（pip-audit が提示する修正版）へ更新する。
- パッチ/マイナー更新であり、Pillow を使用する既存機能（画像アップロード・メディア処理）の回帰は CI の Backend Tests / E2E Tests で担保する。
- 対応 worktree: **study-app-multitenant（primary checkout・track:app）**。本イシューを最優先で develop にマージし、CI ブロックを解消する。

## 実装対象（既知のもの）

|---------|---------|
| backend/requirements.txt | `Pillow==12.2.0` → `Pillow==12.3.0`（1行） |

## スコープ
### 含む
- Pillow のバージョン更新（12.2.0 → 12.3.0）と CI（pip-audit 含む全ジョブ）のグリーン化
### 含まない
- Pillow 以外の依存更新・一括アップデート
- pip-audit ゲート自体の仕様変更（例: 一時 ignore 運用の導入）
- 画像処理機能の仕様変更
