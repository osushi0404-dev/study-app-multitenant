- Q: P6 を plan-writing-rules.md のテンプレートに追加するか → A: 追加する（条件付きセクション13 として）

## 背景/目的
I047 で上流スキル（`/grill-me`・`/plan-issue`・`/implement`）にゼロカバー観点（P3・P5・P8）を追加した。
しかし部分カバー観点（P1・P2・P4・P6・P7）は上流スキルに断片的にしか存在しない状態が残る。

I046 でレビュースキルの同観点を整備した実績をもとに、上流スキルの対応箇所を明示・補完し、
上流→下流で8観点フレームワークが一貫して機能する状態に仕上げる。

対象スキルと補完方針:
- `/grill-me`: P1（業務ロジック・マルチテナント制約）・P4（テスト戦略）の設計確認質問を追加する
- `/plan-issue`: P1（要件適合性）・P4（テスト計画）・P6（性能・UX計画）・P7（設計品質）の確認項目を補完する
- `/implement`: P1（実装と要件の整合）・P6（UX・性能実装確認）・P7（設計品質実装確認）の確認項目を補完する
- P2 は上流スキルに既存の詳細チェックリストがあるため、I046 の追加内容との整合確認のみ行う
- P4（TDD）は `/implement` に既存のため、`/grill-me`・`/plan-issue` での計画段階への追加が主体

## スコープ
### 含む
- `/grill-me` に P1・P4 の設計確認観点を追加する
- `/plan-issue` に P1・P4・P6・P7 の確認セクション/項目を補完する（P2 は I046 との整合確認のみ）
- `/implement` に P1・P6・P7 の確認項目を補完する
- 追加内容が I046 で整備したレビュー観点と対応している（上流・下流で同じ観点を参照できる）

### 含まない
- P3・P5・P8 の上流追加（→ I047）
- レビュースキルの変更（→ I045・I046）
- 新スキルの新設
