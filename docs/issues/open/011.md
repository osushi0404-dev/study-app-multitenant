# I011: dev 環境で Service Worker を無効化 — HMR 妨害とキャッシュ問題の解消

## 背景/目的
- 現在、`pwa.service.ts` が `NODE_ENV` に関係なく Service Worker を登録している
- dev 環境で SW がキャッシュした古いバンドルを配信し、ファイル変更がブラウザに反映されない
- WSL2 + Docker bind mount 環境では inotify が効かず HMR が機能しないため、コンテナ再起動が必要になっている
- SW が `/quiz-management` 等のリクエストを横取りして 503 を返すケースも確認（sw.js:152）
- `NODE_ENV === 'development'` 時に SW を登録しないのが CRA / Next.js / Workbox 等の業界標準

## スコープ
### 含む
- `pwa.service.ts` の `registerServiceWorker()` に `NODE_ENV === 'development'` チェックを追加し、dev では登録しない

### 含まない
- SW 本体（`public/sw.js`）のロジック変更
- 本番環境の SW 挙動の変更
- CACHE_NAME のバージョン管理改善（別途検討）

## 受け入れ条件（Acceptance Criteria）
- [ ] dev 環境（`npm start`）で SW が登録されない
- [ ] ソースファイルを変更してコンテナ再起動後、ブラウザリロードで最新コードが即時反映される
- [ ] 本番ビルド（`npm run build`）では SW が引き続き登録される

## 影響範囲（想定）
- Backend: なし
- Frontend: `src/services/pwa.service.ts`（1 箇所のみ）
- DB: なし
- Config/Infra: なし

## Danger Ops（有/無）
- 無
