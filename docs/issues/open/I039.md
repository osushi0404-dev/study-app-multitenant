# I039: スキル間のファイル名参照の不整合修正

## 関連資料
- 発見経緯: I038 実装前レビュー中に判明（2026-04-10）
- GitHub Issue: #66
- Draft PR: #67

## 背景/目的

各ワークフロースキルが参照するファイルパスの変数パターンが実態の命名規則と一致していない。
また計画書ファイルの命名規則（`plan_I###_{概要}.md`）が他ファイル種別と統一されておらず、
スキル間で参照パターンがバラついている。

**目的**: 全ファイル種別を「概要なし」に統一し、スキル間のファイル名参照を一致させる。

## スコープ

### 含む
- `docs/runbooks/plan-writing-rules.md`: 計画書命名規則を `plan_I###.md` に変更
- `.claude/skills/issue-bootstrap/SKILL.md`: イシューファイル名 `I${ISSUE_NUM}.md`（概要なし）を明示
- `.claude/skills/plan-issue/SKILL.md`: 必読パス `$ARGUMENTS_*.md` → `$ARGUMENTS.md`、生成物 `plan_$ARGUMENTS_{概要}.md` → `plan_$ARGUMENTS.md`
- `.claude/skills/plan-issue-review/SKILL.md`: 計画書パス `$ARGUMENTS_plan.md（または plan_$ARGUMENTS_*.md）` → `plan_$ARGUMENTS.md`
- `.claude/skills/code-review/SKILL.md`: 計画書パス `$ARGUMENTS_plan.md` → `plan_$ARGUMENTS.md`
- `.claude/skills/implement/SKILL.md`: 計画書パス `plan_$ARGUMENTS_*.md` → `plan_$ARGUMENTS.md`
- `.claude/skills/close/SKILL.md`: 計画書パス `plan_I${ISSUE_NUM}_*.md` → `plan_I${ISSUE_NUM}.md`

### 含まない
- 既存計画書ファイルのリネーム（`plan_I###_{概要}.md` のまま残す）
- 上記以外のスキルファイルの変更

## 受け入れ条件（Acceptance Criteria）
- [ ] `plan-writing-rules.md` の命名規則が `plan_I###.md`（概要なし）に更新されている
- [ ] 各スキルの計画書・イシューファイル参照パスが実態の命名規則と一致している
- [ ] `issue-bootstrap/SKILL.md` にイシューファイル名形式（`I${ISSUE_NUM}.md`、概要なし）が明示されている
- [ ] 新規作成される計画書ファイル名が `plan_I###.md` 形式になる

- Frontend: なし
- DB: なし
- Config/Infra: `.claude/skills/` 配下 6 ファイル、`docs/runbooks/plan-writing-rules.md`
