# I028: GitHub 基盤整備：Dependabot 設定と PR テンプレート追加

## 関連資料
- docs/proposals/I026_ai_dev_improvement_proposal.md（改善候補 G・H）

## 背景/目的
- 依存パッケージの脆弱性を自動検出・更新 PR を自動作成する仕組みが未整備
- PR 作成時の本文にひな形がなく、記載内容の統一性・抜け漏れ防止ができていない

## スコープ
### 含む
- `.github/dependabot.yml` の作成（pip・npm・GitHub Actions 週次更新設定）
- `.github/pull_request_template.md` の作成
- `.claude/skills/close/SKILL.md` の更新（step 2 で PR テンプレートを読み込んで PR 説明を構築するよう指示を追加）

### 含まない
- Dependabot が作成した PR のマージ（CI 通過後はユーザーが判断）
- 既存 PR の遡及的な修正

## 受け入れ条件（Acceptance Criteria）
- [ ] `.github/dependabot.yml` が追加され、pip・npm・github-actions の3 ecosystem が週次で監視される
- [ ] `open-pull-requests-limit` が設定されている（各 ecosystem 5件以下）
- [ ] `.github/pull_request_template.md` が追加され、PR 作成時にひな形が自動挿入される
- [ ] PR テンプレートに概要・関連イシュー・変更点・テスト確認・ロールバック手順が含まれる
- [ ] `/close` スキルの step 2 が PR テンプレートを読み込んで PR 説明を構築する
- [ ] CI が通る

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: `.github/` 以下にファイル追加のみ

## Danger Ops（有/無）
- 無
