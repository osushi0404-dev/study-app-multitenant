# I026: AI駆動開発の生産性向上に向けた環境・プロセス総合見直し

## 関連資料
- （検討資料・要件定義・設計メモ等があればここに記載してから /plan-issue を実行する）

## 背景/目的
- 現在のバイブコーディング（Claude Code 活用）運用について、ツール・MCP・外部サービス連携・設定・ワークフロー全般を棚卸しし、改善点を洗い出す
- GitHub 連携・MCP 活用・Claude Code 設定等の最適化余地を検討し、開発生産性と品質をさらに高める

## スコープ
### 含む
- Claude Code の設定・フック・スキルの見直し
- MCP サーバーの活用検討（例：GitHub MCP、その他有用な MCP）
- GitHub / 外部サービス連携の改善検討
- 現行ワークフロー（issue → plan → implement → test → review → merge）の改善点整理
- CLAUDE.md・runbooks・ルールファイルの改訂が必要な箇所の特定

### 含まない
- 個別機能の実装・バグ修正
- アプリケーション本体のコード変更

## 受け入れ条件（Acceptance Criteria）
- [ ] 現状の棚卸しリスト（ツール・設定・ワークフロー）が文書化されている
- [ ] 改善候補が優先度付きでリストアップされている
- [ ] 改善策のうち即実施可能なものが適用されている
- [ ] 必要に応じて CLAUDE.md・runbooks が更新されている

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: .claude/settings.json、CLAUDE.md、docs/runbooks 等

## Danger Ops（有/無）
- 無
