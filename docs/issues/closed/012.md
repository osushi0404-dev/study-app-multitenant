# I012: クローズ済みイシューファイルの open フォルダ残留対応と根本原因修正

## 関連資料
- なし

## 背景/目的
- クローズ済みイシュー（I006, I007, I010, I011）のファイル（イシューファイル・計画書・テストケース・レビュー）が `docs/*/open/` フォルダに残留している
- `/close` スキルの手順が不完全であるか、実行が徹底されていないため、クローズ処理後にファイルが open に残り続けている
- 残留ファイルを整理するとともに、再発しないよう `/close` スキルまたは関連 runbook を修正する

## スコープ
### 含む
- 現在 open フォルダに残っているクローズ済みイシューファイルを deleted（削除）または closed へ整理（I006, I007, I010, I011）
- `/close` スキルを見直し、ファイル移動漏れが起きない仕組みに修正

### 含まない
- 既存の closed フォルダ内のファイル内容の変更
- 新しいイシュートラッキングシステムへの移行

## 受け入れ条件（Acceptance Criteria）
- [ ] `docs/issues/open/` に closed 済みイシューファイルが存在しない
- [ ] `docs/plans/open/` に closed 済み計画書が存在しない
- [ ] `docs/tests/open/` に closed 済みテストケースが存在しない
- [ ] `docs/reviews/open/` に closed 済みレビューファイルが存在しない
- [ ] `/close` スキルに、全ファイル移動を確実に行う手順が明記されている

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし
- Config/Infra: なし
- ドキュメント/スキル: `.claude/skills/close/` および `docs/runbooks/issue-flow.md`

## Danger Ops（有/無）
- 無
