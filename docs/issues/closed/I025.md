# I025: frontend ESLint no-unused-vars 警告の解消

## 関連資料
- I019 振り返り（2026-04-03）: `@typescript-eslint/no-unused-vars` 警告が複数ファイルに残存していることを確認

## 背景/目的
- I019 で `react-hooks/exhaustive-deps` を error 化した際、既存の `@typescript-eslint/no-unused-vars` 警告が複数ファイルに残っていることが判明した
- 未使用の import・変数は可読性を下げ、バンドルサイズの無駄にもなる
- CI で warning として通過しているが、コードベースの品質向上のため解消する

## スコープ
### 含む
- `@typescript-eslint/no-unused-vars` 警告が出ているすべてのファイルの未使用 import・変数を削除
- 対象ファイル（I019 手動テスト時のログより）:
  - `src/App.tsx`
  - `src/components/AIQuestionGenerator.tsx`
  - `src/pages/Dashboard.tsx`
  - `src/pages/Login.tsx`
  - `src/pages/Monitoring.tsx`
  - `src/pages/QuizManagement.tsx`
  - `src/pages/QuizSession.tsx`
  - `src/pages/Register.tsx`
  - `src/pages/Statistics.tsx`
  - `src/pages/UserCreate.tsx`
  - `src/pages/UserManagement.tsx`
  - `src/services/api.ts`
  - `src/services/auth.service.ts`

### 含まない
- `no-unused-vars` を error レベルに引き上げる設定変更（別途検討）
- 未使用コードの機能実装（削除のみ）

## 受け入れ条件（Acceptance Criteria）
- [ ] 上記ファイルで `@typescript-eslint/no-unused-vars` 警告が 0 件になること
- [ ] TypeScript 型チェック（`tsc --noEmit`）が通過すること
- [ ] 既存の Jest テストが通過すること（機能変更なし）

## 影響範囲（想定）
- Backend: なし
- Frontend: 上記 13 ファイル（import 削除・未使用変数削除のみ）
- DB: なし
- Config/Infra: なし
