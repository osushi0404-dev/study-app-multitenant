# I005: 開発DB同期スクリプト整備とREADMEセットアップ手順記載

## 背景/目的
- 複数PC間で同じ開発データを扱えるようにする
- 新しい環境でも `git clone` → 数コマンドで即起動・ログインできる状態を目指す
- pg_dump + クラウドストレージ（Google Drive等）でDBデータを共有する方式を採用

## スコープ
### 含む
- `scripts/db_backup.sh`: DBをpg_dumpしてバックアップファイルを生成するスクリプト
- `scripts/db_restore.sh`: バックアップファイルからDBをリストアするスクリプト
- `README.md`: クローン後のセットアップ手順（.env作成・Docker起動・DBリストア・初回ユーザー作成）

### 含まない
- クラウドストレージへの自動アップロード（手動共有で十分）
- フィクスチャ作成
- 本番環境向けのバックアップ運用

## 受け入れ条件（Acceptance Criteria）
- [ ] `scripts/db_backup.sh` を実行すると `backup_YYYYMMDD.sql` が生成される
- [ ] `scripts/db_restore.sh` を実行するとDBがリストアされる
- [ ] `README.md` にセットアップ手順が記載されており、手順通りに実行すると起動・ログインできる
- [ ] スクリプトはDockerが起動していれば追加インストール不要で動作する

## 影響範囲（想定）
- Backend: なし
- Frontend: なし
- DB: なし（スクリプトのみ）
- Config/Infra: `scripts/` にシェルスクリプト追加、`README.md` 更新

## Danger Ops（有/無）
- 無
