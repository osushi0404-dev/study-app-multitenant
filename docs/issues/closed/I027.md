# I027: GitHub Actions の Lint / Test 失敗を PR 上に annotation で表示する

## 関連資料
- docs/proposals/I026_ai_dev_improvement_proposal.md（I026 改善提案より派生）

## 背景/目的
- 現状、CI の flake8 / ESLint 失敗はログ上にのみ出力され、どのファイルの何行目が問題かを特定するにはログを掘り下げる必要がある
- GitHub Actions の annotation 機能を活用し、失敗箇所を PR の Files changed 上に直接表示することで、Claude Code の修正ループを短縮する

## スコープ
### 含む
- flake8 の出力を GitHub Actions annotation 形式で表示（`flake8-github-annotations` 追加）
- ESLint の出力を GitHub Actions annotation 形式で表示（`eslint-formatter-github` 追加）
- `.github/workflows/ci.yml` の該当ステップを修正

### 含まない
- reviewdog の導入
- 新規 lint ルールの追加・変更
- Jest / pytest の annotation 対応（スコープ外）

## 受け入れ条件（Acceptance Criteria）
- [ ] flake8 の違反が PR の Files changed 上にファイル・行番号付きで表示される
- [ ] ESLint の違反が PR の Files changed 上にファイル・行番号付きで表示される
- [ ] 既存の CI ジョブ（backend-lint / frontend-lint）が引き続き pass する

## 影響範囲（想定）
- Backend: `backend/requirements-dev.txt`
- Frontend: `frontend/package.json`
- DB: なし
- Config/Infra: `.github/workflows/ci.yml`

## Danger Ops（有/無）
- 無
