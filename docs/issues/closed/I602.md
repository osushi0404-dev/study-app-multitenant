## 背景/目的

**背景**: I590 で、画像の配信の 304/412 に守りの見出しを付け、移行 0025 の判定を `problems.utils` から切り離し、`Subject.image_directory` を外した（0027）。レビューはどれも OK だったが、止めない小さな指摘が残った。
**目的**: テストの守りの抜けと、0027 が止まったときの案内の不足を埋め、マイグレーションのテストの補助の写しを 1 か所にまとめる。

### 現状の問題（証拠・再現手順）
1. `backend/problems/tests/test_I590_review_leftovers.py` の TC-03（配信の 200/304/412 の見出し）は `MEDIA_SECURITY_HEADERS` の 3 つのうち `Content-Disposition: inline` を比べていない。304・412 でこの見出しが抜けてもテストが通る（台帳 F1）
2. `backend/problems/migrations/0027_remove_subject_image_directory.py` は値のある科目があると止まるが、止まったときに値を空にする具体的な手順が、エラー文にも手順書にも無い。0010 が旧列の値を `image_directory` に写した経緯があるので、古い控えから戻した DB では止まりうる（台帳 F2・敵対的レビューの Low）
3. 同じテストの TC-01（`media_migration` がアプリのモジュールを読まないかの AST の数え）は、相対の読み込み（`from . import utils`・`from .utils import x`）を数えない（敵対的レビューの Low）
4. マイグレーションを本物で流すテストの補助（`_loader`・`_run`・列の一覧）が `backend/studylogs/tests/test_I492_remove_legacy_study_logs.py`・`backend/problems/tests/test_I587_media_migration.py`・`backend/problems/tests/test_I590_review_leftovers.py` に 3 つ写しで並んでいる。遅延の制約を即時にする回り道を変えるとき、3 か所をそろえて直す必要がある

### 根本原因
- 1・3: テストが守る対象を辞書の全項目・読み込みの全形で回さず、手で選んだ一部だけを比べている
- 2: 止める判定の文言に、止まった後の戻り方を書く決まりが無い
- 4: マイグレーションのテストの共有の置き場が無く、前のテストを写して作ってきた

### 解決方針
- 1: TC-03 で `MEDIA_SECURITY_HEADERS` の全項目を回して比べる
- 2: 0027 の文言は変えない（マージ済みのマイグレーションは書き換えない・規約 §4）。止まったときの戻り方（値を確かめて空にする手順）を手順書かテストの説明に書く。置き場は計画で決める
- 3: TC-01 の数えに相対の読み込み（`level > 0`）も含める。失敗の注入も足す
- 4: `backend/problems/tests/` か共有の場所に補助のモジュールを作り（前例: `problems/tests/i466_data.py` を他のテストが読む）、3 つのテストから読む。置き場は計画で決める
