## MT-7: `/issue-bootstrap` — 採番スクリプトの修正確認

**コード確認:**

| # | 確認項目 | 期待値 |
|---|---------|-------|
| 1 | `printf "%d\n%d\n"` を使った旧コードが残っていない | ✅ |
| 2 | `$((10#${FS_MAX:-0}))` 相当の記述が使われている | ✅ |
| 3 | コメントに「8進数誤解釈を防ぐ」等の説明が付いている | ✅ |

**動作確認（bash で直接検証）:**
```bash
FS_MAX=014
FS_NUM=$((10#${FS_MAX:-0}))
echo "FS_NUM=$FS_NUM"        # 期待値: 14（8進数誤解釈なし）
NEXT=$((FS_NUM + 1))
ISSUE_NUM=$(printf "%03d" $NEXT)
echo "ISSUE_NUM=$ISSUE_NUM"  # 期待値: 015（013 にならない）
```

| # | 確認項目 | 期待値 |
|---|---------|-------|
| 4 | `FS_NUM=14` と出力される | ✅ |
| 5 | `ISSUE_NUM=015` と出力される | ✅ |
