# 手動テスト仕様書: I006 企業・団体ごとの科目追加機能

## 基本情報
- **関連イシュー**: #006
- **関連計画書**: I006_plan
- **作成日**: 2026-03-24

---

## 前提条件

- `role='admin'` のユーザーと `role='user'` のユーザーが存在する
- 開発サーバー（backend + frontend）が起動中
- 管理者ユーザーは組織（Organization）に所属している

---

### TC-004: 科目追加（正常ケース）

|------|------|
| **テスト名** | 日本語名の科目が正常に追加される |

| **期待結果** | - トースト「科目を追加しました」が表示される<br>- 「基礎数学」が一覧に表示される |

| 項目 | 内容 |
|------|------|
| **テスト名** | Enter キーで科目を追加できる |

### TC-007: 既存機能への影響確認

| 項目 | 内容 |
|------|------|
| **テスト名** | 科目追加後も問題の作成・編集が正常動作する |
| **手順** | 科目追加後、問題管理フロー（作成・編集・削除）を実行 |
| **期待結果** | 問題の CRUD が正常に動作する |

| 項目 | 内容 |
|------|------|
| **テスト名** | 問題フィルターの科目プルダウンに追加した科目が表示される |
| **手順** | 科目追加後、問題一覧のフィルター（科目選択）を確認する |
| **期待結果** | 追加した科目がプルダウンに表示される |

| 項目 | 内容 |
|------|------|
| **テスト名** | role='user' は POST /api/subjects/ で 403 になる |
| **手順** | DevTools などで `role='user'` ユーザーのトークンを使い `POST /api/subjects/` を直接実行 |
| **期待結果** | 403 Forbidden が返る |
