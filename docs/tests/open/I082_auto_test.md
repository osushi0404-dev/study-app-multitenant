# I082 自動テスト（auto_test）

対象: ドキュメント追記の存在を grep で機械検証する決定論テスト。
すべて「規定が文書に存在するか（肯定）」「イシュー番号が混入していないか（否定）」を判定する。

## false-green 検証（実装前に実施済み）

肯定存在 TC（TC-A1〜A4）のアンカー文字列は、**実装前にすべて不在（NG / 非ゼロ終了）**であることを確認済み。
よって「正常系で常に OK を返す false-green」ではなく、規定の不在を検出できることを実証済み。
否定 TC（TC-A5）のトークン検出は、`I079` を含むファイル（`docs/issues/open/I082.md`）に対し検出が成立することを確認済み。

| TC | アンカー | 実装前（false-green 確認） |
|----|----------|----------------------------|
| TC-A1 | `稼働中セッションで実証可能な挙動` 他 | NG（不在）✅ |
| TC-A2 | `前倒しで拡張` | NG（不在）✅ |
| TC-A3 | `外部挙動依存の未実証` / 差し戻し表例示行 | NG（不在）✅ |
| TC-A4 | `ハーネス挙動テストの実施環境` / `プレーン default 新規セッション` | NG（不在）✅ |
| TC-A5 | `I079|I080` 検出器 | I082.md で検出成立 ✅ |

## テストケース

### TC-A1: スパイク実証規定（二分岐＋完了基準）が事前調査に存在
```bash
F=docs/runbooks/plan-writing-rules.md
grep -q '外部/ハーネス挙動依存のスパイク実証' "$F" \
 && grep -q '稼働中セッションで実証可能な挙動' "$F" \
 && grep -q '稼働中セッションでは実証不能な挙動' "$F" \
 && grep -q 'スパイク完了基準' "$F" && echo OK || echo NG
```
- 期待: `OK`（exit 0）
- 検証内容: 新規サブセクション・二分岐(1)(2)・完了基準がすべて存在

### TC-A2: 既存「未知リスク先行原則」を参照・拡張（二重定義でない）
```bash
F=docs/runbooks/plan-writing-rules.md
grep -q '前倒しで拡張' "$F" \
 && [ "$(grep -c '未知リスク先行原則' "$F")" -ge 2 ] && echo OK || echo NG
```
- 期待: `OK`（exit 0）
- 検証内容: スパイク規定が「未知リスク先行原則」を参照（出現2回以上＝実装手順の宣言＋スパイク節の参照）し、「前倒しで拡張」と明記

### TC-A3: plan-reviewer に条件付き Blocker gate ＋差し戻し表の例示が存在
```bash
F=.claude/review-agents/plan-reviewer.md
grep -q '外部挙動依存の未実証' "$F" \
 && grep -q '未実証 かつ 実証手段' "$F" \
 && grep -q '問題なし' "$F" \
 && grep -q '未知リスク」と認識する外部挙動前提が未実証で実証手段も無い' "$F" && echo OK || echo NG
```
- 期待: `OK`（exit 0）
- 検証内容: gate bullet・Blocker 条件（未実証かつ実証手段未明記）・「問題なし」分岐・差し戻しファースト原則表への Blocker パターン例示行（レビュー Info 2 対応）が存在

### TC-A4: 手動テスト文書に「実施環境」条件付き列ルールが存在
```bash
F=docs/runbooks/plan-writing-rules.md
grep -q 'ハーネス挙動テストの実施環境' "$F" \
 && grep -q 'プレーン default 新規セッション' "$F" \
 && grep -q '遡及改修は不要' "$F" && echo OK || echo NG
```
- 期待: `OK`（exit 0）
- 検証内容: 実施環境節・実施環境値・遡及改修不要の明記が存在

### TC-A5: 追記文言にイシュー番号が混入していない（一般形）
```bash
grep -qE 'I079|I080' docs/runbooks/plan-writing-rules.md .claude/review-agents/plan-reviewer.md \
 && echo NG || echo OK
```
- 期待: `OK`（exit 0 = どちらのファイルにも `I079`/`I080` が無い）
- 検証内容: 追記後も両ファイルにイシュー番号が含まれない（実装前ベースラインで両ファイルとも未含有を確認済み）
