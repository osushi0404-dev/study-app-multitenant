# I619 手動テスト: パスキーでログイン

前提: 手元のアプリを起動し（`docs/runbooks/frontend-verify.md` §3）、Playwright MCP で `http://localhost:3000` を開く。パスキーの操作は `browser_run_code_unsafe` で CDP の `WebAuthn.enable`・`WebAuthn.addVirtualAuthenticator`（ctap2・internal・resident key・UV あり・自動で触れる）を付けてから行う（§5）。アカウントは確かめ用の利用者（パスワードでログインできるもの）。
