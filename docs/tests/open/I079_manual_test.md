# I079 手動テスト（権限プロンプト挙動）

実装（deny 追加・コミット）完了後、**設定が反映された新規セッション**で確認する。
権限プロンプトの有無はセッション内での実操作で観測する（自動化できないため Claude が実操作を試み、プロンプト発生を観測して記録する）。

| No | 手順 | 期待結果 | 実施者 | 実結果 | 備考 |
|---:|------|----------|--------|--------|------|
| M1 | アプリソース（例: `backend/problems/views.py` の末尾コメント追記）を Edit する | 承諾プロンプトが**出ない**（即時編集） | Claude | | broad allow が効くこと |
| M2 | 高リスク群（例: `backend/Dockerfile` にコメント追記）を Edit する | 承諾プロンプトが**出る**（deny 優先） | Claude | | deny が allow に優先すること |
| M3 | マイグレーション（例: `backend/problems/migrations/0001_*.py` にコメント追記）を Edit する | 承諾プロンプトが**出る** | Claude | | `**/migrations/*.py` グロブ一致 |
| M4 | 依存マニフェスト（例: `frontend/package.json` を Edit）を試行 | 承諾プロンプトが**出る** | Claude | | サプライチェーン保護 |
| M5 | 機密ファイル（例: `backend/.env` の Read/Edit）を試行 | 既存通り**ブロック/プロンプト**（緩和されていない） | Claude | | 既存 deny の不変 |

注: M1〜M4 の検証用コメント追記は確認後に元へ戻す（無改変を維持）。`.env` 等は実在しない場合 deny パターン一致のみ確認する。
