# I452 手動テスト: 今日の復習（ダッシュボードのカード・復習のクイズ）

- 関連: docs/issues/open/I452.md / docs/plans/open/plan_I452.md / GitHub #452 / Draft PR #464
- 前提: app-1 ワークツリーで `docker compose up -d db redis backend frontend` を起こし、`docker compose exec -T backend python manage.py migrate` の後に Playwright MCP で画面を開く（ポートは `docker compose port frontend 3000` で確かめる・`docs/runbooks/frontend-verify.md`）
- 使用アカウント: E2E 用のシードユーザー `e2e_user_a@example.com`（組織 E2E Org A。パスワードは `e2e/.env.e2e` の `E2E_TEST_PASSWORD`）。app-1 の dev DB に無ければ、`docker compose --profile e2e run --rm e2e` の e2e-init（migrate とシード）で作る。ログインの失敗が続くと 5 分の制限がかかるため、パスワードは 1 回で入れる
- 復習する日が来たカードの用意: 画面でクイズに答えてカードを作った後、`docker compose exec -T backend python manage.py shell -c "<コード>"` で、そのアカウントのカードの `next_review_date` と `last_reviewed_at` を前日に倒す（日付をまたぐ代わり）。倒したカードの数と科目を実結果に書く
- 画面のキャプチャは `.evidence/I452/` に保存する
