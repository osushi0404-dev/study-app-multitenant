# I466 手動テスト: 間違い分析と苦手を優先した出題を画面につなぐ

手順は `docs/runbooks/frontend-verify.md`（Playwright MCP・幅 1440×900・画像は `.evidence/I466/`）。アカウントは確かめ用の利用者 `verify_i487@example.com`（専用の組織・科目「確かめ数学」「確かめ英語」各 20 問・起動のたびに答えが作り直される。パスワードは秘密の名前 `E2E_TEST_PASSWORD`）。

準備（test-gate の最初に Claude が行う）: マイグレーションを当てた backend で、`docker compose exec -T backend python manage.py shell` から `verify_i487` の答えを足す（開発の DB だけ・次の起動で作り直されて消える）。
- 確かめ英語 の上級の問題に、今日の日付で 10 問の答え（正解 2・不正解 8。不正解のうち 6 問は `time_taken=2`、ほかは 60 秒）
- 足した後の期待値は、画面の集計の関数を使わずに shell で数える: 全科目の難易度ごとの解答数・正解数（5 問以上・70% 未満のもの）、直近 30 日の解答数・間違いの数・`time_taken > 0` の答えの平均（300 秒で頭打ち）・平均の半分未満の間違いの数
