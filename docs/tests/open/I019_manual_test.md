# I019 手動テスト計画

## 対象
`react-hooks/exhaustive-deps` 有効化後の既存機能デグレ確認

---

## 手動テスト項目

### MT-01: ダッシュボード画面
- [ ] 画面を開いてダッシュボードデータ（統計・グラフ等）が正常に表示される
- [ ] 科目フィルターを変更するとデータが再取得される
- [ ] 「クイズを始める」ボタンが正常に動作する

### MT-02: 統計（Statistics）画面
- [ ] 画面を開いて統計データが表示される
- [ ] 期間（日次/週次/月次）を変更するとデータが再取得される
- [ ] 科目フィルターを変更するとデータが再取得される

### MT-03: モニタリング画面
- [ ] 画面を開いてサーバー情報が表示される
- [ ] 30秒後に自動更新される（またはリフレッシュボタンで手動更新できる）

### MT-04: 問題管理（QuizManagement）画面
- [ ] 問題一覧が表示される
- [ ] 科目フィルターを変更すると問題リストが絞り込まれる
- [ ] 難易度フィルターを変更すると問題リストが絞り込まれる
- [ ] 問題の作成・編集・削除後にリストが更新される

### MT-05: 設定（Settings）画面
- [ ] 画面を開いてユーザー設定が読み込まれる
- [ ] 設定の保存が正常に動作する

### MT-06: ユーザー管理画面
- [ ] ユーザー一覧が表示される
- [ ] ユーザー削除後にリストが更新される

### MT-07: 科目詳細画面
- [ ] 科目詳細情報が正常に表示される
- [ ] org_admin 以外でアクセスした場合にリダイレクトされる

### MT-08: ユーザー編集画面
- [ ] ユーザー情報が初期表示される
- [ ] 保存後に最新データが再取得される

### MT-09: メール認証画面
- [ ] 有効なトークンで認証が完了する
- [ ] 無効なトークンでエラーが表示される

### MT-10: クイズセッション画面
- [ ] 新規クイズセッションが作成され最初の問題が表示される
- [ ] 単一選択問題で選択するとスムーズに自動送信される
- [ ] 複数選択問題で「回答する」ボタンを押すと送信される
- [ ] 結果が表示された後「次の問題」に進める
- [ ] セッション完了画面が正常に表示される

### MT-11: 自動ログアウト（AuthContext）
- [ ] 設定時間（デフォルト 30 分）経過後に自動ログアウト警告が表示される
- [ ] ブラウザ操作（クリック・キー入力等）でタイマーがリセットされる

---

## デグレ確認の重点箇所

| コンポーネント | 変更内容 | 確認ポイント |
|--------------|---------|------------|
| Dashboard.tsx | `fetchDashboardData` → useCallback | フィルター変更時の再フェッチが正常 |
| QuizSession.tsx | `handleSubmitAnswer` → useCallback | 単一選択の自動送信・ボタン押下で二重送信しない |
| UserEdit.tsx | `fetchUser` → useCallback([id]) | 保存後に最新データが表示される |
| UserManagement.tsx | `fetchUsers` → useCallback([]) | 削除後のリスト更新が正常 |
| Monitoring.tsx | `fetchMonitoringData` → useCallback([]) | 自動更新・手動更新ボタンが動作する |
