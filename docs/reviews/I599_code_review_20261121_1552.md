- **`route()`（見張りの付け替え判定）**
  - `$`・バッククォート・かっこ・`;`・`&`・`|`・振り向け・ワイルドカード・改行・`\` を含む形は、付け替えずに止めます。
  - 起動役の形は、プロジェクトの最上位から流したときだけ通します。
