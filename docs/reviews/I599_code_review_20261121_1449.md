# 脆弱性 1: サンドボックス脱出（Python のモジュールの差し替え）: `.claude/hooks/reviewed-hook.sh:38-40`

* **重大度**: High（確信度 8/10）
* **カテゴリ**: `sandbox_escape` / `code_execution`
* **何が起きるか**
  * 起動役は、レビュー前の中身があるかを 2 つの git の確認で判定します。
    * `git diff --quiet "$base" -- scripts/claude`
    * `git ls-files --others --exclude-standard -- scripts/claude`
  * どちらも空なら、40 行目の `exec python3 "$root/$rel"` で、作業ツリーのフックをサンドボックスの外で動かします。`-I` は付いていません。
