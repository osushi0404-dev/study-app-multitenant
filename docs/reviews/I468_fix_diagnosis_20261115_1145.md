- retro は記録の場所だけを書く段階で、その後に手元で関係するテストを流していなかった（D3 は全一覧を読むので、記録のファイルでもテストの対象になる）
- 手で足した R1 の行は「- R」で始まるので D3 の対象外（形は保っている）
- セキュリティ: 該当なし（記録の文言だけ）
