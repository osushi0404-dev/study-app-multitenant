## 影響調査の網羅性評価
- 同型バグについて、「既出の問題から選ぶところ」を `last_n_problems` の grep で 1 か所に絞っている。通常（乱数）モードでも、問題が 1 問だけでなければ、案 A で直前の 1 問が続けて出なくなる。この副作用を記載しており、改善の方向として妥当。

- 軽微な不足として、`next_problem` を呼ぶ API 層（ビューや serializer）が、直前の問題の重複を別に判定していないかは明示されていない。ただし重複の判定はこのサービスに集約されているため、重大とは言えない。
