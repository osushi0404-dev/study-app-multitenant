  - パスは `-z` で読み、変数はすべて引用符で囲んでいます。`eval` や、組み立てた文字列をコマンドとして実行する箇所はありません。
- **`post-review-comment.sh`・PR コメントの投稿**
  - 本文は `--body-file` か引用符つきの引数で渡しており、シェルに解釈させる余地はありません。
  - PR 番号は `gh` の JSON 出力から取っています。
- **`fix-review-lib.sh`・`issue-review.sh`・`plan-issue-review.sh`**
  - 変えたのは、読み取り専用ツールを保ったまま `--system-prompt` から `--agent` に移したことと、時間の上限を足したことだけです。
- **`expected_ci_jobs`**
  - YAML は `yaml.safe_load` で読んでおり、危ない読み込み方ではありません。
- **`.gitignore`**
  - `.claude/settings.local.json` を足しただけで、個人の設定をコミットしにくくなる側の変更です。

## 対象外として除いたもの

- `adversarial-reviewer` に Bash ツールを渡している件は、悪用の道筋が AI を文章で誘導するもの（対象外）に限られます。そのうえ呼び出し元は手元の review-gate だけなので、報告していません。
