## 指摘一覧（助言）

|--------|------|---------|---------|
| Info | 自己完結度 | `IsOrgAdmin` が `role == 'admin'` のみで判定されると明記されているが、**他組織 admin が他組織の問題を操作できないか**（組織スコープのフィルタを含むか）が触れられていない。制約に「`request.user.role == 'admin'`」とだけ書かれており、テナント境界の保証が既存クラスにあるかは計画フェーズで要確認。（ただし本イシューのスコープは「非 admin 禁止」に明確に絞られているため起票はブロックしない） | 制約・引き継ぎ情報 |
