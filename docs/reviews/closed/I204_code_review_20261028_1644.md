  - CI が起動するのは `pull_request` で、`pull_request_target` ではありません。
  - `GITHUB_TOKEN` は `permissions: contents: read`（読み取りだけ）のままです。

- **確かめるコマンドの実行（`check-tools.sh:52` の `bash -c "$probe"`）**
