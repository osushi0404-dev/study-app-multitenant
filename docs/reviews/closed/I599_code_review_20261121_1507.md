## 結論
この PR は、サンドボックスの外で動く範囲を狭めています。変更前は `bash scripts/claude/*` がまるごとサンドボックスの外で動き、フックも作業ツリーのファイル（サンドボックスから書き換えられる）をそのまま動かしていました。変更後は次のとおりです。

- 外に出るのは `python3 .claude/hooks/unreviewed.py run <決まった名前>` だけです。外で動かすのは `scripts/claude/` にレビュー前の中身が無いときに限られ、名前は固定の一覧で確かめます。引数はシェルを通さずに渡します。
- フックは、ブランチが develop から分かれた時点の写しで動きます。写しの置き場所（`~/.cache/claude-reviewed-hooks`）は、サンドボックスから書けません。
- 見張りは、起動の形が「プロジェクトの最上位で、つなぎ・置き換え・振り向け・ワイルドカード・前置きの代入の無い 1 つのコマンド」でなければ止めます。このため、別の場所に偽の `.claude/hooks/unreviewed.py` を置いて外で動かす経路は塞がれています。
