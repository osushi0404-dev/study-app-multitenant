# イシュー自己完結度レビュー [I209]

## 判定: 要補足
重要セクションに空欄はありません。ただ、判定基準が未確定のままで、AC に検証できない箇所があります。どちらも下の指摘のとおりで、計画着手前に補足を推奨します。

## 未記入の重要セクション
なし。「解決方針」と「ローカルファイルの扱い」は「未定・grill-me で確認」と明示宣言されているので、欠落とは数えません。

## 次のアクションの推奨
要補足です。`/grill-me` で次の 3 点を先に決めてから `/plan-issue` に進むことを推奨します。
1. 判定基準
2. ユーザーに確認する条件
3. 記録の置き場所と、AC2 の検証方法

起票者が理解したうえで、これらに「未特定・grill-me で確認」と明記して進めることもできます。
