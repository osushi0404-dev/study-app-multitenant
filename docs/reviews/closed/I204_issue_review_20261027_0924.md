## 次のアクションの推奨
未確定箇所を埋めるため、`/grill-me` を推奨します。論点は次の 3 つです。
- 一覧の範囲
- 一覧と `.pre-commit-config.yaml` の版の持ち方（二重管理の回避）
- CI で pre-commit を使う場合の `ci.yml` の変更範囲

この 3 点が決まれば、`/plan-issue` に進めます。
