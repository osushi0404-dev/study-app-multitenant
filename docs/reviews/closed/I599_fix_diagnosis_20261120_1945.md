# I599 fix-loop 診断メモ（2026-11-20 19:45・止める指摘 F12・ユーザーの承認で 1 周延長）

記録: `docs/reviews/I599_code_review_20261120_1931.md`。review-gate ⇄ fix-loop の 5 回目の上限に当たり、ユーザーの判断で 1 周だけ延長（`docs/reviews/open/I599_review.md` の自律判断の記録）。

## 失敗分解
- F12（High・STOP=ac:3）: `scripts/claude/` に変更が無い状態で `bash scripts/claude/issue-review.sh --file "$DRAFT"` を見張りに通すと書き換えが付き、中で動く。期待: 外で動く（AC4「レビュー済みのスクリプトは今までどおり外で動く」）。実際: F11 の規則（`$`・`` ` ``・`(`・`)`・`{`・`}` があれば読み切らずに中）が、変更の有無を見る前に効く。スキルの手順の `--file "$DRAFT"`・`N=$(bash scripts/claude/issue-source.sh …)` が中に回り、`claude -p`・gh が動かない
- 同じ原因の F13（Medium）: `gh pr edit --body "$(cat <<'EOF' … bash scripts/claude/x.sh … EOF)"` のように本文に書いただけで当たり、gh が中に回る

## 根本原因
- F11 の規則を「変更の有無」より前に置いた。変更が無ければ、どのスクリプトもレビュー済みなので、読み切れなくても外へ出してよい（危ないのは、スクリプトの位置の語そのものが変数・置き換えで、どこのファイルでも指せる形だけ）
- 当たりの判定（`triggered`）が文字の中のどこでも `bash scripts/claude/` に当たる（本文の文字にも）
- セキュリティ: 守りを弱める方向の変更なので、残る穴を書く（下）

## 対応方針（全案＋推奨）
- 案 A（推奨・ユーザーが選んだもの）:
  1. 置き換え・かっこを含むコマンドでも、`bash` の直後のスクリプトの位置の語に `$`・`` ` ``・`..` などがあれば、変更の有無によらず中で動かす（TC-07 の形。どこのファイルでも指せるため）
  2. それ以外の置き換え・かっこを含むコマンドは、`scripts/claude/` にレビュー前の中身（BASE との差・追跡していない新規・git が無視するファイル）があるときだけ中で動かす。無ければ外のまま
  3. `test-session.sh` を含むなら、変更の有無によらず承認。変更が無いときは書き換えを付けない（承認すれば外で動く。F14 の承認の意味が無い問題も消える）
  4. 当たりの判定を「コマンドの先頭の形」（行頭・`;`・`&`・`|`・`(`・`$(` の後に、空白・`X=…` の前置き・`timeout`／`nice`／`nohup`／`env`／`time` を挟んで `bash scripts/claude/`）に絞る。本文の途中の文字には当たらない（F13）
  - 残る穴（受け入れ・計画書 8 に足す）: 変更が無いときに、置き換え・変数で引数を組み立てて `run-all.sh`・`stress-repeat.sh` に外のファイルを渡す形。`$(…)` はサンドボックスの外に出す一覧に当たらず中で動く（`docs/runbooks/danger-ops.md`「外に出すコマンドの書き方」）。`"$VAR"` は同じ呼び出しで値を入れると前置きの代入で中で動き、Bash ツールは呼び出しの間で環境変数を持ち越さないので、外から入れられない
- 案 B（方式の見直し）: 変更があるあいだ `bash scripts/claude/…` を一律に承認制。ハーネスのイシューで承認が多く出る（ユーザーの判断で採らない）
- 案 C（受け入れ）: F12 を残す。スキルの手順が中に回って失敗する（採らない）

## 影響調査
- `$`・かっこを含む `bash scripts/claude/…` の呼び出し（スキル・手順書）: `.claude/skills/issue-bootstrap/SKILL.md`（`--file "$DRAFT"`）・`.claude/skills/grill-me/SKILL.md`（`N=$(bash scripts/claude/issue-source.sh …)`・`> "$DRAFT"`）・`.claude/skills/plan-issue/SKILL.md`（`ISSUE_FILE=$(bash scripts/claude/issue-source.sh snapshot …)`）。変更が無いときは外のまま（このうち `$(…)`・`>` の形は、もともと公式のサンドボックスが中で動かす形）

- テスト: TC-26 を「変更なし: 外のまま／変更あり: 中／test-session: 常に承認」に直し、TC-27（F12 のスキルの形・F13 の本文の形）を足す。各 FG
