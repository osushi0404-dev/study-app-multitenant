# 敵対的レビュー [I599] ── 観点: 2. テストの false-green・tautology

## findings
反証失敗（新規指摘なし）。探索した仮説:

- **FG-G9b が空振りして常に合格する。**
  - `sed` は `[[ … && -c "$p" ]] && continue` の 1 行だけを削除する。
  - 削除後は、未追跡の `.bashrc` が `is_record_path` で記録の場所の外と判定され、DIRTY になって exit 1 になる。
  - `sed` のパターンが実装の行に一致しなかった場合は、何も削除されず exit 0 になるので、FG は期待の 1 に対して落ちる。つまり FG は偽陽性にならない。
- **`GC=… g_rc g9` の環境変数の前置が効かない。**
  - `g_rc` は関数で、`$GC` を実行時に参照する（198 行）。
  - bash では関数呼び出しの前置の代入が関数の実行中に有効なので、差し替えた写しが使われる。
  - 写しは `GATE_CHECK_LIB="$LIB"` を引き継ぐので、位置が変わっても動く。
- **G9b が実装の再確認になっている。**
  - G9b は、通常の未追跡ファイルは 1（G9）、文字デバイスだけなら 0、という対比になっている。
  - 除外を外した FG と対になるので、これは実装をなぞる確認ではなく、実際に判定が変わることを確かめている。
- **G9b が `/dev/null` へのシンボリックリンクで作られている件。**
  - リンクを数えない穴を 0 と期待して固定してしまう。
  - これはコードレビューの F30・F31 と同一なので、再報告しない。
- **TC-18 など他の TC への影響。**
  - 今回の差分で触れていないので、前の周の確認（FG 13 本が PASS）を引き継ぐ。
