- ラベル、更新を待つ日数（cooldown）、更新のまとめ方（groups）、無視する版（ignore）の設定だけです。自動マージはありません。
- Dependabot の PR からは secrets が見えず、ワークフローも読み取り権限なので、権限を上げる道はありません。

**`.pre-commit-config.yaml`**
- 版を固定した `check-jsonschema` の `check-dependabot` フックを足しただけです。

**対象外:** `scripts/claude/tests/*.sh` はテスト専用なので、除外の決まりに従って見ていません。

## 結論
全体としてはセキュリティが良くなる変更です。依存物の取得先を固定し、CI の固定パスワードとパスワードが残りうる trace の公開をやめ、土台のイメージを指紋で固定しています。High・Medium の脆弱性は新しく入っていません。
