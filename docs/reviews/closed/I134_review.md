## 敵対的レビュー観点（独立サブエージェント向け・「合格を反証せよ」）
- 「全件反映済み」を反証せよ: TC-02/03 の合格が、引用・コードフェンス内の行頭 `**背景**:`（I134 型の decoy）による誤合格でないか。ラベルはあるが `## 背景/目的` セクション外に置かれたファイルは無いか。
- 「挿入のみで無改変」を反証せよ: TC-06 の比較基準は**実装者自身が退避した原本**である。退避が更新後に行われた・別イシューの body を退避した等で比較が自己言及化していないか（退避時刻と GitHub 編集履歴の整合を突け）。また gh の body 正規化（改行コード・末尾空行）が diff を汚して偽 NG／それを握り潰す偽 OK になっていないか。
- 「要約が既存記述由来」を反証せよ: 追記された背景・目的に、イシュー本文に書かれていない事実・解釈（会話コンテキスト由来の知識）が混入していないか。サンプルでなく無作為抽出で数件突き合わせよ。
- 引き継ぎスクリプトを反証せよ: タイトル前方一致（`I###:`）での GitHub 番号解決が誤マッチする組（例: 番号が接頭辞関係にあるタイトル）は無いか。awk 挿入が `## 背景/目的` 見出しを持たないファイルに対して無挿入のまま正常終了（偽成功）しないか。
- 冪等性を反証せよ: 引き継ぎスクリプトや GitHub 更新を二重実行した場合にラベル 2 行が重複挿入されないか（skip 条件が両ラベル AND であることの穴: 片方だけ入っているファイルで挿入すると重複しないか）。
