## 確認した範囲

- **`.claude/hooks/reviewed-hook.sh`**: 引数は `scripts/claude/hooks/*.py` の形に限られ、`..` も弾かれます。git は `GIT_*` の環境変数を外し、命令を動かす設定（`core.fsmonitor`・`core.hooksPath`・`submodule.recurse`）を無効にして呼んでいます。写しは `~/.cache/claude-reviewed-hooks/` に置かれ、ここはサンドボックスから書けません。一時フォルダを作ってから置き換えるので、途中の状態が使われることもありません。基準を求められないときは作業ツリーのフックを動かしますが、これは変更前と同じ動きなので、新しい穴にはなりません。
- **`.claude/hooks/unreviewed.py`**: git は配列の引数で呼び、shell を通していません。`rewrite_command` は、差し込む文の中の `'`・`\`・改行を消し、ファイル名も `[A-Za-z0-9._/-]` 以外を置き換えています。このため、ファイル名を細工して書き換え後のコマンドに別の命令を差し込むことはできません。判定に失敗したときは、サンドボックスの中で動かす側に倒れます。
- **`scripts/claude/hooks/pretooluse_guard.py`**: 書き換え（`updatedInput`）を返す道は、止める判定（`_block`）を飛ばしません。止める判定には書き換える前の元のコマンドが渡ります。読み込む判定ファイルは `.claude/hooks/` にあり、サンドボックスから書けません。読み込みに失敗したときは、サンドボックスの中で動かします。
- **`scripts/claude/code-review.sh`**: 追加されたのは、ゲートの行を手元で流す範囲を狭める処理だけです。判定できないときは流しません。
- **`.claude/settings.json`**: フックの呼び方を起動役を通す形に変えただけです。許可（allow）やサンドボックスの外に出す一覧は広がっていません。
