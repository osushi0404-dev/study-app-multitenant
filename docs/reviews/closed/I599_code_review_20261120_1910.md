## 確かめた内容

この変更は守りを足すものです。レビュー前の `scripts/claude/` の中身を、サンドボックスの外（`excludedCommands` の `bash scripts/claude/*`）で動かさないようにしています。新しく生まれる攻撃の入口がないかを、次の点で確かめました。

- **`.claude/hooks/reviewed-hook.sh`（起動役）**
  - 引数のパスは `scripts/claude/hooks/*.py` だけを受け付け、`..` は拒否しています。パスをたどって別の場所のファイルを動かすことはできません。
  - `GIT_*` の環境変数を外し、`core.fsmonitor`・`core.hooksPath`・`submodule.recurse` を無効にして git を呼んでいます。`.git/config` を書き換えて任意のコマンドを動かす道はふさがれています。

- **`.claude/hooks/unreviewed.py`（判定の本体）**
  - git は引数の配列で呼び、shell を通していません。コマンドを差し込む余地はありません。
  - 判定できないときや上限を超えたときは、サンドボックスの中で動かす側に倒れます（`check()` の例外処理と `_Limit`）。
  - `rewrite_command()` は、`echo '…'` に埋める文字を `[A-Za-z0-9._/-]` に絞り、`'`・`\`・改行も消しています。単一引用符を抜け出して別のコマンドを差し込むことはできません。
  - `test-session.sh` の引数は許可の表で絞っています。`--permission-mode` は確認を外さないモードだけ、`--settings` は develop と中身が同じ設定ファイルだけを承認なしで通します。
- **`.claude/settings.json`**: フックの起動を起動役経由に替えただけです。起動役は Bash から書けない `.claude/hooks/` に置かれています。
