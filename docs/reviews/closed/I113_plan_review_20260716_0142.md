**補足説明（口語）**

Blocker 1件で差し戻しです。主な問題は `resolve_status()` の bash サブシェル設計バグです。

この関数は常に `S=$(resolve_status)` という形（コマンド置換）で呼ばれます。コマンド置換はサブシェルを作るため、内部の `exit 1` はそのサブシェルを終了するだけで、親スクリプトには届きません。また `echo` でエラーメッセージを出しても、それはターミナルではなく変数 S に格納されてしまいます。

結果、`gh pr view` が失敗すると:
- S = "⚠️ mergeStateStatus 取得失敗"（エラーメッセージが格納される）
- sync モードの `*)` デフォルト分岐にマッチ → "✅ 追従不要" を表示して **exit 0（安全確認をすり抜ける）**

step 0 のチェックが空振りになるのは、この機能の根本目的を損なうため Blocker 判定にしました。修正は `>&2` リダイレクト + `return 1` への変更、呼び出し側の `|| exit 1` 追加で対応できます。
