- **高リスクとみなすファイルの範囲を狭めました。** 自動で「高リスク」と判定する対象（`path_risk_trigger`）から `scripts/claude/hooks/*`・`.claude/skills/*`・`CLAUDE.md` などを外し、`.github/*`・`.pre-commit-config.yaml`・`.secrets.baseline`・`pretooluse_guard.py`・`.claude/settings*.json` に絞っています。
  - 「GitHub が最後の守り」という方針（I181）に沿った意図的な変更で、悪用できる脆弱性ではありません。
  - ただし、外したファイルの変更は、組み込みの `/security-review` と敵対的レビューが自動では動かなくなります。
- **補足:** 依頼の手順にある「別のエージェントで探す → 1 件ずつ誤検知を確かめる」は使いませんでした。差分を直接読んで判断し、誤検知を確かめる候補が 1 件も残らなかったため、その段は不要でした。
