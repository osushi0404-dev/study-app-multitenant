**補足（Warning の実装時対応案）**

Warning の `-[qL]` 齟齬は実装フェーズで即座に解消できます。ゲートセクションコメントの該当行を

```
`grep -q 文言 file`（存在）/ `! grep -q 文言 file`（不在）
```

↓

```
`grep -q 文言 file`（存在）/ `grep -L 文言 dir/*`（不在ファイル一覧）/ `! grep -q 文言 file`（不在）
```

のように `-L` を追記するか、あるいは AC3 文言側を「主要パターンが存在」に緩和するかを実装前に決め切ることで、TC-03 の検証範囲と AC3 の要件が一致します。どちらの方針でも Blocker ではないので `/implement I117` を先に進めてください。
