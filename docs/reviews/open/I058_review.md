# I058 レビュー

## レビュー観点チェックリスト

### 要件適合性
- [ ] 受け入れ条件をすべて満たしているか
- [ ] スコープ外の実装が含まれていないか

### セキュリティ
- [ ] `set -euo pipefail` でエラー処理が適切か
- [ ] 引数検証（パストラバーサル防止）が実装されているか

### ベストプラクティス
- [ ] `claude -p` を使用し `agentId`・`<usage>` が混入しないか
- [ ] 出力正規化（末尾スペース・改行）が実装されているか
- [ ] CI タイムアウトが適切に設定されているか

### 後方互換
- [ ] `/plan-issue-review`・`/code-review` スキルから従来通り呼び出せるか
