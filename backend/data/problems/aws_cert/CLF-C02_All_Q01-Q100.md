### Q1
**試験**：CLF-C02  
**問題タイプ**：単一選択（4択・正解は1つ）
**難易度**：基礎
**問題文**：AWS の共有責任モデルにおいて、Amazon EC2 上で稼働する OS のパッチ適用は誰の責任ですか。  
**選択肢**：  
- A. AWS  
- B. お客様  
- C. AWS とお客様の共同  
- D. サポートプラン次第  
**正解**：B  
**解説**：ゲスト OS・アプリ・データの保護はお客様の責任。AWS はハイパーバイザーや物理インフラを保護します。
