# AWS認定クラウドプラクティショナー サンプル問題

本ファイルは、問題データのマークダウン形式のサンプルです。

## 問題作成時の注意事項

1. **問題番号ヘッダー**: `### Q[番号]` の形式（見出しレベル3）
2. **必須フィールド**: `**問題文**：`, `**選択肢**：`, `**正解**：`
3. **選択肢形式**: `- A. [内容]` のように、`-` + スペース + アルファベット + `.` + スペース
4. **正解指定**: `**正解**：B` のように選択肢IDで指定（複数の場合は `A,C`）

### Q1
**試験**：CLF-C02
**問題タイプ**：単一選択（4択・正解は1つ）
**問題文**：AWS の共有責任モデルにおいて、Amazon EC2 上で稼働する OS のパッチ適用は誰の責任ですか。
**選択肢**：
- A. AWS のみの責任
- B. お客様のみの責任
- C. AWS とお客様の共同責任
- D. サポートプランによって異なる
**正解**：B
**解説**：ゲスト OS・アプリ・データの保護はお客様の責任です。AWS はハイパーバイザーや物理インフラを保護します。共有責任モデルでは、「クラウドのセキュリティ（AWS）」と「クラウド内のセキュリティ（お客様）」が明確に分離されています。

### Q2
**試験**：CLF-C02
**問題タイプ**：単一選択（4択・正解は1つ）
**問題文**：AWS のどのサービスを使用すると、グローバルなコンテンツ配信を低レイテンシで実現できますか。
**選択肢**：
- A. Amazon S3
- B. Amazon CloudFront
- C. Amazon EC2
- D. AWS Direct Connect
**正解**：B
**解説**：Amazon CloudFront は、AWS のコンテンツ配信ネットワーク（CDN）サービスです。世界中のエッジロケーションを使用して、静的および動的なウェブコンテンツを低レイテンシで配信します。S3 は静的コンテンツのストレージ、EC2 はコンピューティングリソース、Direct Connect は専用線接続サービスです。
---

### Q3
**試験**：CLF-C02
**問題タイプ**：単一選択（4択・正解は1つ）
**問題文**：AWS の無料利用枠（Free Tier）には、どのような種類がありますか。
**選択肢**：
- A. 常に無料、12ヶ月間無料、トライアルの3種類
- B. 常に無料のみ
- C. 12ヶ月間無料のみ
- D. トライアルのみ
**正解**：A
**解説**：AWS 無料利用枠には、1) 常に無料（例: Lambda の月間 100 万リクエスト）、2) 12ヶ月間無料（例: EC2 t2.micro 月 750 時間）、3) トライアル（例: Amazon Inspector の 15 日間）の3種類があります。サービスによって適用される無料利用枠の種類が異なります。

### Q4
**試験**：CLF-C02
**問題タイプ**：複数選択（2つ以上の正解）
**問題文**：AWS Well-Architected Framework の5つの柱として正しいものを2つ選択してください。
**選択肢**：
- A. 運用上の優秀性
- B. セキュリティ
- C. スピード
- D. 柔軟性
**正解**：A,B
**解説**：AWS Well-Architected Framework の5つの柱は、1) 運用上の優秀性、2) セキュリティ、3) 信頼性、4) パフォーマンス効率、5) コスト最適化です。「スピード」と「柔軟性」は AWS の利点ですが、Well-Architected Framework の柱ではありません。
---

### Q5
**試験**：CLF-C02
**問題タイプ**：単一選択（4択・正解は1つ）
**問題文**：AWS のリージョンとアベイラビリティーゾーンの関係として正しいものはどれですか。
**選択肢**：
- A. 1つのリージョンには必ず2つのアベイラビリティーゾーンがある
- B. 1つのリージョンには2つ以上のアベイラビリティーゾーンがある
- C. リージョンとアベイラビリティーゾーンは同じものである
- D. アベイラビリティーゾーンは複数のリージョンにまたがっている
**正解**：B
**解説**：AWS リージョンは地理的な場所を示し、各リージョンには2つ以上の物理的に分離されたアベイラビリティーゾーン（AZ）があります。AZ は独立した障害ドメインとして機能し、高可用性を実現します。リージョンによって AZ の数は異なりますが、最低2つ以上存在します。
