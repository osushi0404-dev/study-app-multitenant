# ハーネスのテスト（scripts/claude/tests/run-all.sh）が頼る道具の一覧（I204・I211）。どの道具をどう確かめるかの正（CI の Harness Tests と手元で同じ）。
# run-all.sh は uv の環境（scripts/claude/tests/.venv）で流れ、冒頭で check-tools.sh がこの一覧を確かめ、合わなければテストを流さずに不合格にする。
# 版の正は同じフォルダの .python-version（python3）・uv.lock（python の道具）・pyproject.toml の required-version（uv）。CI はこれらだけを読む（install を書かない）。
# 列: 名前 | 確かめるコマンド | 版（- は問わない・lock は .python-version / uv.lock とぴったり） | 入れ方（手元）
# 確かめるコマンドに縦棒（列の区切り）は書かない。版を上げる手順: docs/runbooks/onboarding.md「手元の準備（ハーネスのテスト）」
python3 | python3 --version | lock | bash scripts/claude/tests/run-all.sh で流す（uv が .python-version の python を入れる）
PyYAML | python3 -c 'import yaml; print(yaml.__version__)' | lock | bash scripts/claude/tests/run-all.sh で流す（uv が uv.lock の版を入れる）
uv | uv --version | - | pipx install uv==<pyproject.toml の required-version の版>（docs/runbooks/onboarding.md）
git | git --version | - | sudo apt install git（CI は runner に最初からある）
docker compose | docker compose version | - | Docker Desktop の WSL 連携を有効にする（CI は runner に最初からある）
pre-commit | pre-commit --version | lock | bash scripts/claude/tests/run-all.sh で流す（uv が uv.lock の版を入れる）
