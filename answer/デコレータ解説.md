# Pythonのデコレータ解説

## デコレータとは？
デコレータは、既存の関数やクラスに新しい機能を追加するPythonの機能です。
`@記号`を使って関数の上に書きます。

## 基本的な例

### 1. シンプルなデコレータ
```python
# デコレータの定義
def my_decorator(func):
    def wrapper():
        print("関数実行前")
        func()
        print("関数実行後")
    return wrapper

# デコレータの使用
@my_decorator
def say_hello():
    print("Hello!")

# 実行
say_hello()
# 出力:
# 関数実行前
# Hello!
# 関数実行後
```

### 2. 実用的な例：実行時間計測
```python
import time

def measure_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__}の実行時間: {end - start}秒")
        return result
    return wrapper

@measure_time
def slow_function():
    time.sleep(2)
    return "完了"

slow_function()  # 実行時間: 2.00秒
```

## UserRegistrationViewでの使用例

```python
@method_decorator(ratelimit(key='ip', rate='3/5m', method='POST'), name='post')
class UserRegistrationView(generics.CreateAPIView):
    ...
```

この場合の動作：
1. `ratelimit`デコレータが`post`メソッドに適用される
2. IPアドレスごとに5分間で3回までのアクセス制限
3. 制限を超えるとエラーを返す

## デコレータの仕組み

デコレータは実は以下と同じ：
```python
# @デコレータを使った場合
@my_decorator
def my_function():
    pass

# 手動で適用した場合（同じ結果）
def my_function():
    pass
my_function = my_decorator(my_function)
```

## よく使われるデコレータ

### Django/DRFでよく見るもの
- `@login_required` - ログインが必要
- `@permission_required` - 特定の権限が必要
- `@api_view` - 関数ベースのAPIビュー
- `@ratelimit` - アクセス回数制限
- `@cache_page` - ページキャッシュ

### 標準ライブラリ
- `@property` - メソッドをプロパティとして扱う
- `@staticmethod` - 静的メソッド
- `@classmethod` - クラスメソッド

## まとめ
デコレータは「関数を引数に取り、新しい関数を返す関数」です。
既存のコードを変更せずに機能を追加できる便利な仕組みです。
